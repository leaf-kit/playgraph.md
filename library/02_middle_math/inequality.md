# 부등식 / Inequality

두 수 또는 식의 크기를 비교하는 관계식입니다.

A mathematical statement comparing two values using inequality signs.

$$ax + b > 0$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

부등식은 **"이것보다 크다, 작다"를 수학으로 쓰는 방법**이야! 🎢

놀이기구를 타려면 키가 120cm **이상**이어야 해. 이걸 수학으로 쓰면 $키 \geq 120$이야! 방정식이 "딱 같다(=)"를 찾는 거라면, 부등식은 "이 범위 안에 있다"를 찾는 거란다.

용돈이 5,000원인데 사탕 한 개에 500원이야. 몇 개까지 살 수 있을까? $500 \times x \leq 5000$, 그러니까 10개까지! 남는 돈이 있어도 괜찮으니까 부등식을 쓰는 거야! 😊

### 📐 중학생 눈높이

부등식은 등호(=) 대신 $>$, $<$, $\geq$, $\leq$를 사용하는 수학적 문장이에요. 방정식의 해가 하나의 값이라면, 부등식의 해는 **범위**입니다.

시험에서 평균 80점 이상을 받으려면? 3과목 합이 240점 이상이어야 하니까 $x_1 + x_2 + x_3 \geq 240$. 두 과목에서 75점, 85점을 받았다면 마지막 과목은? $75 + 85 + x \geq 240$ → $x \geq 80$! 80점 이상을 받아야 해요.

**주의!** 부등식에서 양변에 음수를 곱하거나 나누면 **부등호 방향이 바뀌어요!** 이것만 기억하면 부등식 풀기는 방정식만큼 쉬워요.

### 🎓 고등학생 눈높이

부등식은 **최적화 문제**의 기본 도구입니다. 선형 부등식의 해 영역(feasible region)을 구하고, 그 안에서 목적함수의 최댓값/최솟값을 찾는 것이 **선형계획법(Linear Programming)**이에요.

코시-슈바르츠 부등식, AM-GM 부등식 등의 유명한 부등식들은 수학 전반에 걸쳐 강력한 도구로 활용됩니다. 특히 절댓값 부등식 $|a + b| \leq |a| + |b|$ (삼각부등식)은 해석학과 위상수학의 기본이 됩니다.

## 🔍 수식을 단계별로 풀어볼까요?

$2x - 3 > 0$을 함께 풀어봅시다!

**1단계:** 상수항을 이항해요 → $2x > 3$

**2단계:** 양변을 계수 2로 나눠요 → $x > \frac{3}{2}$

**3단계:** 해를 해석해요 → $x$는 $1.5$보다 **큰** 모든 수!

**4단계:** 수직선에 표현하면 → $1.5$에 빈 원(○)을 찍고 오른쪽으로 화살표!

선생님 팁: 빈 원(○)은 그 점을 포함하지 않는 것($>$, $<$), 채운 원(●)은 포함하는 것($\geq$, $\leq$)이에요! 🌈

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 계수와 상수를 바꾸면 수직선 위에서 해의 영역(색칠된 부분)이 변하는 것을 볼 수 있어요.
- **관찰 결과:** $a$가 양수일 때와 음수일 때 해의 방향이 반대가 되며, $a = 0$일 때는 부등식의 해가 전체 실수이거나 공집합이 된다는 것을 확인할 수 있어요.
- **연결 질문:** $a$의 부호를 바꾸면 해의 영역이 왜 반대가 될까요? 이것이 "음수를 곱하면 부등호 방향이 바뀐다"는 규칙과 어떻게 연결될까요?

## 🔗 개념 연결 고리

- **이전 개념:** 일차방정식(linear-equation) — 부등식은 방정식의 등호를 부등호로 바꾼 것이에요. 풀이 방법도 비슷하죠!
- **다음 개념:** 연립부등식, 이차부등식 — 여러 조건을 동시에 만족하는 범위를 찾아요.
- **관련 개념:** 절댓값 부등식, 함수의 최대·최소 문제와 연결됩니다.

## 실생활 활용

- **예산 제한:** "교통비와 식비를 합쳐서 50,000원 이하로 써야 해" → $교통비 + 식비 \leq 50000$
- **속도 제한:** "이 도로에서 시속 80km를 넘으면 안 돼" → $속도 \leq 80$
- **최소 점수 조건:** "장학금을 받으려면 평균 90점 이상이어야 해" → $평균 \geq 90$
- **키 제한:** 놀이공원 놀이기구 탑승 조건 "120cm 이상" → $키 \geq 120$
- **택배 무게:** "택배 한 박스 무게가 30kg을 넘으면 추가 요금이 붙어요" → $무게 \leq 30$
- **시험 합격선:** "60점 미만이면 재시험" → $점수 \geq 60$이 합격 조건!
