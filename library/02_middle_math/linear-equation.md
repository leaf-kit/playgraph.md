# 일차방정식 / Linear Equation

미지수의 최고 차수가 1인 방정식입니다.

An equation where the highest power of the variable is 1.

$$ax + b = 0$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

일차방정식은 **"숨어있는 수를 찾는 퀴즈"**야! 🎯

"사탕 몇 개에 3개를 더했더니 7개가 됐어. 원래 몇 개였을까?" 이걸 수식으로 쓰면 $x + 3 = 7$이야. $x = 4$! 사탕은 4개였어!

저울 놀이를 상상해 봐. 양쪽이 같은 무게여야 균형이 맞잖아? 한쪽에 뭔가를 더하면 다른 쪽에도 같은 걸 더해야 해. 이게 바로 방정식을 푸는 방법이야! ⚖️

### 📐 중학생 눈높이

일차방정식은 $ax + b = 0$ 형태로, 미지수 $x$의 **최고 차수가 1**인 방정식이에요.

용돈 문제로 풀어볼까요? "한 달 용돈에서 매주 5,000원씩 쓰면 4주 후에 2,000원이 남아요. 용돈은 얼마였을까?" → $x - 5000 \times 4 = 2000$ → $x = 22,000$원!

방정식을 풀 때의 핵심 원리: **등호 양쪽에 같은 연산을 하면 등호가 유지된다!** 이것만 기억하면 어떤 일차방정식이든 풀 수 있어요.

### 🎓 고등학생 눈높이

일차방정식은 **선형대수학**의 가장 기본적인 단위입니다. 미지수가 여러 개인 **연립일차방정식** $Ax = b$는 행렬과 벡터로 표현되며, 가우스 소거법이나 크래머 공식으로 풀 수 있어요.

일차방정식의 해의 존재성과 유일성은 계수 $a \neq 0$이면 보장되며, 이는 **역함수의 존재 조건**과도 연결됩니다. 최적화 문제에서 제약조건을 일차방정식/부등식으로 표현하는 것이 **선형계획법(Linear Programming)**의 핵심이에요.

## 🔍 수식을 단계별로 풀어볼까요?

$2x - 4 = 0$을 함께 풀어봅시다!

**1단계:** 목표를 정해요 → $x$를 혼자 남기는 것!

**2단계:** 상수항을 이항합니다 → $2x = 4$ (양변에 4를 더했어요)

**3단계:** 계수로 나눕니다 → $x = \frac{4}{2} = 2$ (양변을 2로 나눴어요)

**4단계:** 검산! $2 \times 2 - 4 = 4 - 4 = 0$ ✅ 맞았어요!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 계수 a와 상수 b를 바꾸면 해의 위치가 수직선 위에서 이동하는 것을 볼 수 있어요.
- **관찰 결과:** $a$의 크기가 커지면 해가 0에 가까워지고, $b$의 크기가 커지면 해가 멀어져요. $a = 0$이면 해가 없거나 무수히 많다는 것도 확인할 수 있어요.
- **연결 질문:** 계수 $a$가 0이 되면 어떤 일이 벌어질까요? $0 \cdot x + b = 0$에서 해는 몇 개일까요?

## 🔗 개념 연결 고리

- **이전 개념:** 등식의 성질, 사칙연산 — 등식의 양변에 같은 연산을 적용하는 원리가 기초예요.
- **다음 개념:** 일차함수(linear-function) — 일차방정식의 해는 일차함수의 그래프와 x축의 교점이에요.
- **관련 개념:** 부등식(inequality), 연립방정식으로 확장됩니다.

## 실생활 활용

- **가격 계산:** "사과 3개와 배 2개를 사니 8,000원이었다. 사과 한 개가 1,000원이면 배 한 개는?" → $3 \times 1000 + 2x = 8000$
- **속도·시간·거리 관계:** "시속 60km로 달리면 서울에서 부산까지 몇 시간?" → $60x = 400$
- **나이 문제:** "아빠는 나보다 28살 많고, 아빠 나이가 내 나이의 3배야" → $x + 28 = 3x$
- **핸드폰 요금:** "기본료 11,000원에 데이터 1GB당 2,000원, 총 요금이 19,000원이면 사용 데이터는?" → $11000 + 2000x = 19000$
- **거스름돈:** "10,000원을 내고 물건을 샀더니 3,500원을 거슬러 받았다. 물건 가격은?" → $10000 - x = 3500$
- **시험 점수:** "5과목 평균이 85점이 되려면 마지막 과목에서 몇 점을 받아야 할까?" → $\frac{80+90+75+88+x}{5} = 85$
