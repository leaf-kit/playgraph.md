# 좌표평면 / Coordinate Plane

x축과 y축이 만나는 평면 위에 점의 위치를 나타내는 체계입니다.

A two-dimensional surface where points are located using x and y coordinates.

$$P(x, y)$$

```math-anim
type: coordinate-plane
params:
  pointX: { default: 3, min: -5, max: 5, step: 0.5, label: { kr: "x 좌표", en: "x coordinate" } }
  pointY: { default: 4, min: -5, max: 5, step: 0.5, label: { kr: "y 좌표", en: "y coordinate" } }
  showQuadrants: { default: true, label: { kr: "사분면 표시", en: "Show Quadrants" } }
```
