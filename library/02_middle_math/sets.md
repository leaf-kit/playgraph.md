# 집합 / Sets

공통된 성질을 가진 것들의 모임을 집합이라 합니다.

A collection of distinct objects grouped together.

$$A \cup B, \; A \cap B$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

집합은 **"같은 종류끼리 모아놓은 그룹"**이야! 📦

장난감 상자를 생각해 봐! 레고만 모은 상자, 인형만 모은 상자 — 이것이 집합이야! "우리 반에서 안경 쓴 친구들"도 하나의 집합이고, "축구를 좋아하는 친구들"도 집합이야.

안경도 쓰고 축구도 좋아하는 친구가 있다면? 그 친구는 **두 집합 모두**에 들어가! 이걸 **교집합**이라고 해. 두 그룹을 합치면? **합집합**! 벤 다이어그램으로 그리면 한눈에 볼 수 있어! 😊

### 📐 중학생 눈높이

집합은 수학에서 **가장 기본적인 개념** 중 하나예요!

우리 반 30명 중 영어 학원 다니는 학생(집합 A)이 18명, 수학 학원 다니는 학생(집합 B)이 15명, 둘 다 다니는 학생이 8명이라면?

- $A \cap B = 8$ (교집합: 둘 다 다니는 학생)
- $A \cup B = 18 + 15 - 8 = 25$ (합집합: 적어도 하나는 다니는 학생)
- 어디에도 안 다니는 학생: $30 - 25 = 5$명

핵심 연산: $n(A \cup B) = n(A) + n(B) - n(A \cap B)$ — 이 공식은 정말 자주 쓰여요!

### 🎓 고등학생 눈높이

집합론은 **현대 수학의 토대**입니다. 칸토어가 체계화한 집합론에서 자연수, 정수, 유리수, 실수가 모두 집합으로 정의되죠.

**드모르간 법칙** $(A \cup B)^c = A^c \cap B^c$, $(A \cap B)^c = A^c \cup B^c$은 논리학과 프로그래밍의 불 대수(Boolean Algebra)와 직접 대응합니다. 집합의 **기수(Cardinality)** 개념은 "무한의 크기 비교"를 가능하게 하며, 칸토어의 대각선 논법으로 $|\mathbb{N}| < |\mathbb{R}|$임을 증명할 수 있어요.

## 🔍 수식을 단계별로 풀어볼까요?

$A = \{1, 2, 3, 4, 5\}$, $B = \{3, 4, 5, 6, 7\}$일 때 합집합과 교집합을 구해 봅시다!

**1단계:** 교집합(공통 원소) → $A \cap B = \{3, 4, 5\}$

**2단계:** 합집합(모든 원소, 중복 제거) → $A \cup B = \{1, 2, 3, 4, 5, 6, 7\}$

**3단계:** 차집합 → $A - B = \{1, 2\}$ (A에만 있는 원소)

**4단계:** 검산! $n(A \cup B) = n(A) + n(B) - n(A \cap B) = 5 + 5 - 3 = 7$ ✅

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 집합 A, B의 크기와 교집합 크기를 조절하면 벤 다이어그램의 겹치는 영역이 변하고, 합집합의 원소 수가 실시간으로 계산돼요.
- **관찰 결과:** 교집합이 커질수록 합집합은 작아지고(중복이 많으니까!), 교집합이 0이면 두 집합은 서로소(disjoint)라는 것을 시각적으로 이해할 수 있어요.
- **연결 질문:** 교집합의 크기가 집합 A의 크기와 같아지면 어떤 관계가 될까요? (힌트: $A \subseteq B$를 생각해 보세요!)

## 🔗 개념 연결 고리

- **이전 개념:** 분류와 논리 — "~이면서 동시에 ~인 것"이라는 논리적 사고가 집합의 기초예요.
- **다음 개념:** 확률(probability-basic) — 사건을 집합으로 표현하면 확률의 덧셈/곱셈 법칙이 자연스럽게 나와요.
- **관련 개념:** 명제와 논리, 함수의 정의역과 치역도 집합 개념이에요.

## 실생활 활용

- **데이터베이스 검색:** "서울에 사는 AND 20대인" 고객 검색은 교집합 연산이에요!
- **설문 조사 분석:** "영화를 좋아하는 학생 OR 음악을 좋아하는 학생"의 수를 구할 때 합집합 공식을 써요.
- **논리적 분류:** 생물학에서 동물을 분류하는 것(포유류, 조류, 파충류...)도 집합의 활용이에요.
- **SNS 친구 관계:** "나와 친구이면서 너와도 친구인 사람" = 교집합! 인스타그램의 "공통 팔로워"가 바로 이거예요.
- **쇼핑 필터:** 온라인 쇼핑에서 "빨간색 AND 사이즈 M AND 1만원 이하" 필터링은 세 집합의 교집합이에요.
- **음악 추천:** "이 노래를 좋아하는 사람들이 또 좋아하는 노래" 추천은 집합의 교집합을 분석한 결과예요.
