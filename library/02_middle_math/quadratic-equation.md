# 이차방정식 / Quadratic Equation

미지수의 최고 차수가 2인 방정식으로, 근의 공식으로 풀 수 있습니다.

An equation with the variable raised to the second power.

$$ax^2 + bx + c = 0$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

이차방정식은 **"제곱이 들어간 수수께끼"**야! 🎪

정사각형 울타리를 만들고 싶은데 넓이가 25㎡가 되어야 해. 한 변의 길이는? $x \times x = 25$, 그러니까 $x^2 = 25$! 답은 $x = 5$m야!

공을 위로 던지면 올라갔다가 내려오잖아? 공의 높이를 나타내는 식이 바로 이차방정식이야. 공이 땅에 떨어지는 시간을 찾는 것이 이차방정식을 푸는 거란다! 🏀

### 📐 중학생 눈높이

이차방정식 $ax^2 + bx + c = 0$은 최대 **2개의 근(해)**을 가질 수 있어요.

교실에서 직사각형 게시판을 만드는데, 가로가 세로보다 3cm 길고 넓이가 40㎠라면? 세로를 $x$라 하면 $x(x+3) = 40$, 즉 $x^2 + 3x - 40 = 0$! 인수분해하면 $(x+8)(x-5) = 0$이니까 $x = 5$cm (음수는 길이가 될 수 없으니까요).

근의 공식을 알면 모든 이차방정식을 풀 수 있어요: $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$

### 🎓 고등학생 눈높이

이차방정식에서 **판별식** $D = b^2 - 4ac$의 부호에 따라 근의 성질이 결정됩니다: $D > 0$이면 서로 다른 두 실근, $D = 0$이면 중근, $D < 0$이면 허근(복소근).

**근과 계수의 관계(비에타 공식)**는 $\alpha + \beta = -\frac{b}{a}$, $\alpha\beta = \frac{c}{a}$이며, 이는 대수학의 기본정리와 연결됩니다. 나아가 3차, 4차 방정식의 해법, 그리고 5차 이상은 일반적 대수적 풀이가 불가능하다는 **아벨-루피니 정리**로 이어져요.

## 🔍 수식을 단계별로 풀어볼까요?

$x^2 - 3x + 2 = 0$을 함께 풀어봅시다!

**1단계:** 인수분해를 시도해요 → 곱해서 2, 더해서 -3이 되는 두 수를 찾자!

**2단계:** $-1 \times -2 = 2$이고 $-1 + (-2) = -3$ → 찾았어요!

**3단계:** $(x - 1)(x - 2) = 0$으로 인수분해!

**4단계:** 각 인수가 0이 되는 값 → $x = 1$ 또는 $x = 2$

**5단계:** 검산! $1^2 - 3(1) + 2 = 0$ ✅, $2^2 - 3(2) + 2 = 0$ ✅

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 계수 a, b, c를 조절하면 포물선의 모양이 변하고, x축과 만나는 점(근)의 개수가 바뀌는 것을 볼 수 있어요.
- **관찰 결과:** 포물선이 x축과 2점에서 만나면 서로 다른 두 근, 1점에서 접하면 중근, 만나지 않으면 실근이 없다는 것을 시각적으로 확인할 수 있어요. 이것이 판별식 $D$의 의미랍니다!
- **연결 질문:** 계수 $a$의 부호를 바꾸면 포물선이 어떻게 변하나요? 왜 그런 변화가 일어날까요?

## 🔗 개념 연결 고리

- **이전 개념:** 인수분해(factoring)와 제곱근(square-root) — 이차방정식의 두 가지 풀이법의 기초예요.
- **다음 개념:** 이차함수의 그래프, 판별식, 근과 계수의 관계로 이어져요.
- **관련 개념:** 완전제곱식, 포물선의 꼭짓점, 최댓값/최솟값 문제와 연결됩니다.

## 실생활 활용

- **포물선 궤적:** 농구공을 던질 때 공의 경로는 포물선이에요. 공이 림에 도달하는 시간은 이차방정식으로 구합니다!
- **면적 최적화:** "울타리 20m로 가장 넓은 직사각형 만들기" → 이차방정식으로 최대 넓이를 구해요.
- **이윤 최대화:** 물건 가격을 올리면 판매량이 줄어드는 관계에서 최대 이윤을 찾는 문제예요.
- **브레이크 거리:** 자동차 속도와 제동 거리의 관계는 이차식 $d = v^2/(2\mu g)$으로 표현돼요.
- **분수의 높이:** 분수대에서 물줄기의 최고 높이와 도달 거리를 이차방정식으로 계산해요.
- **건축 아치:** 교량이나 건물의 아치 구조는 포물선 모양이며 이차식으로 설계됩니다.
