# 일차함수 / Linear Function

그래프가 직선인 함수로, 기울기와 y절편으로 결정됩니다.

A function whose graph is a straight line.

$$y = ax + b$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

일차함수는 **"규칙적으로 변하는 것"**을 그림으로 나타낸 거야! 📏

물탱크에 1분마다 물이 2리터씩 차오른다고 상상해 봐. 처음에 3리터가 있었다면, 1분 후 5리터, 2분 후 7리터... 이 관계를 그래프로 그리면 예쁜 **직선**이 돼! 이게 바로 일차함수야.

계단을 올라가는 것처럼 일정하게 올라가거나, 미끄럼틀처럼 일정하게 내려가는 직선이란다! 🎢

### 📐 중학생 눈높이

일차함수 $y = ax + b$에서 $a$는 **기울기**(변화의 빠르기), $b$는 **y절편**(시작점)이에요.

택시 요금을 생각해 봅시다! 기본요금 4,800원에 1km당 1,000원이 추가되면: $y = 1000x + 4800$. 여기서 기울기 1,000은 "1km당 요금 증가분", y절편 4,800은 "타자마자 내는 기본요금"이에요.

기울기가 양수면 그래프가 오른쪽 위로 올라가고, 음수면 내려가요. **기울기의 절댓값**이 클수록 더 가파른 직선이 됩니다!

### 🎓 고등학생 눈높이

일차함수는 **아핀 변환(Affine Transformation)**의 1차원 버전으로, $f(x) = ax + b$에서 $a \neq 0$이면 전단사 함수(bijection)이므로 역함수 $f^{-1}(x) = \frac{x-b}{a}$가 존재합니다.

미적분의 관점에서, 일차함수의 도함수 $f'(x) = a$는 상수이며, 이는 **변화율이 일정**하다는 것을 의미해요. 이를 일반화하면 다항함수, 나아가 **테일러 전개**에서 1차 근사가 바로 일차함수입니다: $f(x) \approx f(a) + f'(a)(x-a)$.

## 🔍 수식을 단계별로 풀어볼까요?

$y = 2x + 1$의 그래프를 그려 봅시다!

**1단계:** y절편을 찾아요 → $x = 0$일 때 $y = 2(0) + 1 = 1$ → 점 $(0, 1)$

**2단계:** 기울기를 해석해요 → 기울기 $a = 2$는 "x가 1 증가하면 y가 2 증가"한다는 뜻!

**3단계:** 두 번째 점을 찾아요 → $x = 1$일 때 $y = 2(1) + 1 = 3$ → 점 $(1, 3)$

**4단계:** 두 점 $(0, 1)$과 $(1, 3)$을 직선으로 연결하면 그래프 완성! 📈

선생님 팁: 기울기 = $\frac{y의 변화량}{x의 변화량}$이에요. "가로로 1칸 갈 때 세로로 몇 칸 가느냐"로 기억하면 쉬워요! 🌈

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 기울기 슬라이더를 움직이면 직선이 회전하고, y절편을 바꾸면 직선이 위아래로 평행이동하는 것을 볼 수 있어요.
- **관찰 결과:** 기울기가 직선의 방향(오르막/내리막)과 가파르기를 결정하고, y절편이 직선의 위치를 결정한다는 것을 직관적으로 이해할 수 있어요.
- **연결 질문:** 기울기가 같고 y절편이 다른 두 직선은 어떤 관계일까요? 절대 만나지 않는 직선은 어떤 조건일까요?

## 🔗 개념 연결 고리

- **이전 개념:** 일차방정식(linear-equation)과 좌표평면(coordinate-plane) — 일차방정식의 해를 좌표평면에 나타내면 직선이 돼요.
- **다음 개념:** 이차함수, 연립방정식 — 두 일차함수의 교점은 연립방정식의 해와 같아요.
- **관련 개념:** 비례(proportion)는 $b = 0$인 특수한 일차함수예요!

## 실생활 활용

- **택시 요금 구조:** 기본요금 + 거리당 요금 = $y = ax + b$ 형태예요. 기울기는 km당 요금, y절편은 기본요금!
- **온도 변환:** 섭씨를 화씨로 바꾸는 공식 $F = \frac{9}{5}C + 32$도 일차함수예요.
- **급여 계산:** 시급 9,860원에 교통비 5,000원이 추가되면 $y = 9860x + 5000$ (x는 근무시간).
- **수도 요금:** 기본료에 사용량 비례 요금이 더해지는 구조가 일차함수입니다.
- **스프링의 늘어남:** 훅의 법칙 $F = kx$에서 힘과 늘어난 길이의 관계도 일차함수예요.
- **배터리 소모:** 스마트폰 배터리가 시간당 일정하게 줄어드는 것도 (음의 기울기를 가진) 일차함수로 모델링할 수 있어요.
