# 제곱근 / Square Root

제곱하여 a가 되는 수를 a의 제곱근이라 합니다.

A number that when multiplied by itself gives the original number.

$$\sqrt{a} = b \;\Leftrightarrow\; b^2 = a$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

제곱근은 **"어떤 수를 두 번 곱하면 이 수가 될까?"** 라는 질문의 답이야! 🍬

정사각형 타일이 9개 있어. 이걸 정사각형 모양으로 배열하면 한 줄에 몇 개씩 놓아야 할까? 3개씩 3줄! 그래서 $\sqrt{9} = 3$이야.

25개의 초콜릿을 정사각형으로 예쁘게 배열하면? 5개씩 5줄! $\sqrt{25} = 5$! 이렇게 제곱근은 **"정사각형의 한 변 찾기"**라고 생각하면 쉬워! 😊

### 📐 중학생 눈높이

제곱근은 거듭제곱의 **역연산**이에요. $3^2 = 9$이니까 $\sqrt{9} = 3$인 거죠.

방 면적이 16㎡인 정사각형 방의 한 변의 길이는? $\sqrt{16} = 4$m예요! 축구장의 대각선 거리를 구할 때도 제곱근이 필요하고, 피타고라스 정리에서도 빗변을 구할 때 꼭 사용해요.

주의할 점! $\sqrt{2} = 1.41421356...$처럼 끝나지 않는 소수가 되는 경우가 많아요. 이런 수를 **무리수**라고 하며, 유리수와는 다른 신비로운 수랍니다.

### 🎓 고등학생 눈높이

제곱근은 $a^{1/2}$로 표현할 수 있으며, 일반적으로 $n$제곱근 $\sqrt[n]{a} = a^{1/n}$으로 확장됩니다.

$\sqrt{2}$가 무리수임을 증명하는 **귀류법**은 수학적 증명의 아름다운 예시입니다. 또한 제곱근 함수 $f(x) = \sqrt{x}$의 정의역은 $x \geq 0$이며, 이는 실수 범위에서 **복소수**로의 확장을 암시합니다 — $\sqrt{-1} = i$가 바로 그것이죠.

## 🔍 수식을 단계별로 풀어볼까요?

$\sqrt{16}$을 함께 구해 봅시다!

**1단계:** 질문을 바꿔 봅시다 → "어떤 수를 제곱하면 16이 될까?"

**2단계:** 후보를 찾아봐요
- $3^2 = 9$ (16보다 작아요)
- $4^2 = 16$ (딱 맞아요! ✨)
- $5^2 = 25$ (16보다 커요)

**3단계:** $4 \times 4 = 16$이므로, $\sqrt{16} = 4$

**4단계:** 참고로, $(-4)^2 = 16$이기도 해요! 그래서 16의 제곱근은 $\pm 4$이지만, $\sqrt{16}$은 양의 제곱근 **4**만을 의미한답니다.

선생님 팁: 완전제곱수(1, 4, 9, 16, 25, 36...)가 아닌 수의 제곱근은 무리수가 돼요. $\sqrt{2}, \sqrt{3}, \sqrt{5}$ 같은 수들이 바로 그래요! 🌈

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 값을 바꾸면 정사각형의 크기가 변하고, 한 변의 길이(제곱근)가 함께 표시돼요.
- **관찰 결과:** 넓이가 9인 정사각형의 한 변은 3, 넓이가 2인 정사각형의 한 변은 1.414...로, 완전제곱수가 아닌 경우 한 변의 길이가 깔끔하게 떨어지지 않는다는 것을 눈으로 확인할 수 있어요.
- **연결 질문:** 넓이가 2인 정사각형은 실제로 존재할 수 있을까요? 그 한 변의 길이를 자로 정확히 잴 수 있을까요?

## 🔗 개념 연결 고리

- **이전 개념:** 거듭제곱(exponents) — 제곱의 역연산이 바로 제곱근이에요.
- **다음 개념:** 피타고라스 정리(pythagorean-theorem) — 빗변의 길이를 구할 때 제곱근이 꼭 필요해요.
- **관련 개념:** 무리수의 발견, 실수의 체계, 복소수의 시작점이 됩니다.

## 실생활 활용

- **대각선 길이 계산:** 가로 3m, 세로 4m인 방의 대각선은 $\sqrt{3^2 + 4^2} = \sqrt{25} = 5$m예요.
- **면적에서 한 변 구하기:** 100㎡ 정사각형 텃밭의 한 변은 $\sqrt{100} = 10$m입니다.
- **피타고라스 정리 활용:** 5m 사다리를 벽에 기대었을 때 바닥에서 얼마나 떨어져야 안전한지 계산할 수 있어요.
- **화면 크기:** TV의 대각선 길이를 인치로 표현하는데, 가로세로 길이에서 $\sqrt{가로^2 + 세로^2}$으로 구해요.
- **지진 규모:** 리히터 규모는 에너지의 제곱근과 관련된 로그 스케일을 사용해요.
- **카메라 조리개:** f/1.4, f/2, f/2.8... 이 숫자들은 $\sqrt{2}$의 거듭제곱이에요!
