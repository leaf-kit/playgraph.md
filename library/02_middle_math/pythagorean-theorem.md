# 피타고라스 정리 / Pythagorean Theorem

직각삼각형에서 빗변의 제곱은 나머지 두 변의 제곱의 합과 같습니다.

$$a^2 + b^2 = c^2$$

여기서:
- **a**, **b**: 직각을 이루는 두 변 (밑변과 높이)
- **c**: 빗변 (가장 긴 변)

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

피타고라스 정리는 **"직각삼각형의 비밀 규칙"**이야! 🔺

직각삼각형의 세 변에 각각 정사각형 블록을 붙여보자. 짧은 두 변에 붙인 정사각형 블록의 개수를 더하면, 긴 변(빗변)에 붙인 정사각형 블록의 개수와 **항상 같아!**

예를 들어, 한 변이 3칸, 다른 변이 4칸이면: $3 \times 3 = 9$개 + $4 \times 4 = 16$개 = **25개**! 그리고 빗변은? $5 \times 5 = 25$개! 정말 신기하지? ✨

### 📐 중학생 눈높이

직각삼각형에서 **빗변(c)의 제곱은 나머지 두 변(a, b)의 제곱의 합**과 같아요.

교실 대각선을 구해볼까요? 가로 6m, 세로 8m인 교실의 대각선은:
$c = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10$m!

유명한 피타고라스 수: $(3, 4, 5)$, $(5, 12, 13)$, $(8, 15, 17)$. 이 조합들은 외워두면 문제 풀 때 정말 유용해요! 건설 현장에서도 **3-4-5 법칙**으로 직각을 확인한답니다.

### 🎓 고등학생 눈높이

피타고라스 정리는 **유클리드 기하학**의 핵심 정리로, 300가지 이상의 증명이 알려져 있습니다.

좌표평면에서 두 점 사이의 **거리 공식** $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$은 피타고라스 정리의 직접적인 응용이에요. 이를 3차원으로 확장하면 $d = \sqrt{\Delta x^2 + \Delta y^2 + \Delta z^2}$, $n$차원으로 일반화하면 **유클리드 노름**이 됩니다. 나아가 내적 공간에서의 **코시-슈바르츠 부등식**과도 연결되죠.

## 🔍 수식을 단계별로 풀어볼까요?

$a = 3$, $b = 4$일 때 빗변 $c$를 구해 봅시다!

**1단계:** 공식을 써요 → $a^2 + b^2 = c^2$

**2단계:** 값을 대입해요 → $3^2 + 4^2 = c^2$

**3단계:** 계산해요 → $9 + 16 = c^2$ → $25 = c^2$

**4단계:** 양변에 제곱근! → $c = \sqrt{25} = 5$

선생님 팁: 세 변의 길이가 주어졌을 때, 가장 긴 변의 제곱이 나머지 두 변의 제곱의 합과 같은지 확인하면 직각삼각형인지 판별할 수 있어요! 🌈

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 두 변의 길이를 조절하면 직각삼각형의 모양이 변하고, 각 변 위의 정사각형 넓이가 함께 표시돼요.
- **관찰 결과:** 짧은 두 변 위의 정사각형 넓이를 합하면 항상 빗변 위의 정사각형 넓이와 같다는 것을 시각적으로 확인할 수 있어요. 이것이 피타고라스 정리의 **기하학적 의미**랍니다!
- **연결 질문:** 만약 $a^2 + b^2 > c^2$이면 이 삼각형은 어떤 삼각형일까요? (힌트: 예각/둔각을 생각해 보세요!)

## 역사

기원전 6세기 그리스의 수학자 피타고라스가 정리한 것으로 알려져 있지만, 이보다 훨씬 이전에 바빌로니아와 인도에서도 이 관계를 알고 있었습니다.

## 🔗 개념 연결 고리

- **이전 개념:** 제곱근(square-root)과 거듭제곱 — 빗변을 구하려면 제곱근을 알아야 해요.
- **다음 개념:** 단위원(unit-circle)과 삼각비 — 삼각함수의 기초가 되며, $\sin^2\theta + \cos^2\theta = 1$의 출발점이에요.
- **관련 개념:** 좌표평면에서의 거리 공식, 닮음(similar-triangles)과 연결됩니다.

## 활용

- **거리 계산**: 두 점 사이의 거리를 구할 때 사용합니다
- **건축**: 직각을 확인하는 데 활용됩니다 (3-4-5 삼각형)
- **내비게이션**: GPS 좌표 간의 직선거리를 계산합니다
- **TV 화면 크기:** 55인치 TV는 대각선이 55인치라는 뜻! 가로세로 길이에서 피타고라스 정리로 구해요.
- **축구장 대각선:** 가로 105m, 세로 68m인 축구장의 대각선은 $\sqrt{105^2 + 68^2} \approx 125.1$m예요.
- **사다리 안전 거리:** 5m 사다리를 벽에 기대려면 바닥에서 얼마나 떨어뜨려야 하는지 계산할 수 있어요.
