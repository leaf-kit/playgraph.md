# 정수 / Integers

양의 정수, 0, 음의 정수를 모두 포함하는 수의 집합입니다.

The set of whole numbers including negatives, zero, and positives.

$$\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

안녕, 친구들! 정수는 우리가 아는 숫자 세계를 **두 배로 넓혀주는 마법의 숫자**야! 🍬

사탕이 3개 있으면 +3이야. 그런데 친구에게 사탕을 2개 빌려야 하면? 그건 -2라고 쓸 수 있어! 0은 사탕이 하나도 없는 상태고, -2는 "2개를 갚아야 하는 상태"라고 생각하면 돼.

엘리베이터를 떠올려봐! 1층, 2층, 3층은 양의 정수, 지하 1층(-1), 지하 2층(-2)은 음의 정수야. 0층은 없지만, 수학에서는 0도 아주 중요한 정수란다! 😊

### 📐 중학생 눈높이

정수는 자연수(1, 2, 3, ...)에 **0과 음의 정수**를 합친 수의 체계입니다.

여러분의 용돈 통장을 생각해 볼까요? 잔고가 5,000원이면 +5,000, 친구에게 3,000원을 빌렸다면 -3,000으로 표현할 수 있어요. 정수의 덧셈과 뺄셈은 이런 **실제 돈의 흐름**과 똑같이 작동합니다.

축구에서 골 득실차도 정수예요. 3골을 넣고 1골을 먹었다면 골 득실차는 +2, 반대라면 -2가 되죠. 이렇게 정수는 **방향이 있는 양**을 표현할 때 정말 유용합니다.

### 🎓 고등학생 눈높이

정수 집합 $\mathbb{Z}$는 **덧셈에 대한 군(Group)** 구조를 가지며, 정수환(Integer Ring) $(\mathbb{Z}, +, \times)$은 대수학의 기본이 됩니다.

정수의 성질 중 **정렬 원리(Well-Ordering Principle)** — 양의 정수의 공집합이 아닌 부분집합은 항상 최솟값을 가진다 — 는 수학적 귀납법의 기초가 됩니다. 또한 정수론에서 소인수분해의 유일성(산술의 기본정리)은 정수의 핵심 성질이에요.

## 🔍 수식을 단계별로 풀어볼까요?

자, 정수의 구조를 차근차근 살펴볼게요!

**1단계:** 자연수를 떠올려 봅시다 → $1, 2, 3, 4, \ldots$

**2단계:** 여기에 0을 추가합니다 → $0, 1, 2, 3, \ldots$ (이것을 "음이 아닌 정수"라 해요)

**3단계:** 이제 각 자연수에 대응하는 음수를 추가합니다 → $\ldots, -3, -2, -1$

**4단계:** 모두 합치면 정수의 집합이 완성됩니다!

$$\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$$

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 수직선 위에서 두 정수 A와 B의 위치가 표시되고, 양수는 오른쪽, 음수는 왼쪽에 나타나는 것을 볼 수 있어요.
- **관찰 결과:** 정수는 수직선 위에서 일정한 간격으로 배열되며, 0을 기준으로 양수와 음수가 대칭을 이루고 있다는 것을 확인할 수 있어요.
- **연결 질문:** 두 정수 사이의 거리는 어떻게 구할 수 있을까요? $|A - B|$는 왜 항상 양수일까요?

## 🔗 개념 연결 고리

- **이전 개념:** 자연수와 수직선 — 자연수를 확장하여 정수 개념이 탄생했어요.
- **다음 개념:** 유리수(rational-numbers) — 정수와 정수의 비율로 더 넓은 수의 세계가 열립니다.
- **관련 개념:** 수직선(number-line)에서의 위치 표현, 절댓값의 개념으로 이어져요.

## 실생활 활용

- **영하 온도:** 겨울철 기온이 -10°C라고 하면, 이것은 0°C보다 10도 낮다는 뜻이에요. 일기예보에서 매일 만나는 정수랍니다!
- **해발 고도:** 에베레스트 산은 해발 +8,849m, 사해는 해발 -430m예요. 기준점(해수면)을 0으로 놓고 위아래를 정수로 표현하죠.
- **은행 잔고:** 통장에 10,000원이 있으면 +10,000, 대출이 있으면 음수로 표현할 수 있어요.
- **엘리베이터 층수:** 지상 5층(+5)에서 지하 2층(-2)으로 내려가면 몇 층을 이동한 걸까요? 바로 $5 - (-2) = 7$층이에요!
- **게임 점수:** 게임에서 보너스 점수(+)와 페널티 점수(-)를 합산할 때도 정수의 덧셈을 사용합니다.
- **시간대:** 한국은 UTC+9, 뉴욕은 UTC-5처럼 시간대도 정수로 표현해요.
