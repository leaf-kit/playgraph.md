# 미분방정식 / Differential Equations

미지 함수와 그 도함수 사이의 관계를 나타내는 방정식입니다.

Equations involving a function and its derivatives.

$$\frac{dy}{dx} = f(x, y)$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

미분방정식은 **"변화의 규칙을 알면 미래를 예측할 수 있다!"** 는 아이디어예요!

토끼가 번식하는 것을 생각해 봐요:
- 🐰 토끼가 많을수록 새끼도 더 많이 태어나요
- 지금 토끼 수에 따라 "늘어나는 속도"가 달라져요

"늘어나는 속도 = 지금 있는 수의 절반" 같은 규칙을 쓰면, 내일, 모레, 1년 뒤 토끼가 몇 마리인지 예측할 수 있어요! 이 규칙을 수학으로 쓴 것이 미분방정식이에요.

### 📐 중학생 눈높이

보통 방정식은 "미지수"를 찾지만, 미분방정식은 **"미지 함수"** 를 찾아요!

$\frac{dy}{dx} = 2x$는 "도함수가 $2x$인 함수 $y$를 찾아라"는 뜻이에요.
→ 양변을 적분하면: $y = x^2 + C$ (적분 상수 $C$는 초기 조건으로 결정!)

$\frac{dy}{dx} = ky$는 "변화율이 현재값에 비례하는 함수"를 찾아라!
→ 해: $y = Ce^{kx}$ (지수함수적 성장/감소!)

### 🎓 고등학생 눈높이

미분방정식의 분류:
- **상미분방정식 (ODE):** 변수가 1개 → $\frac{dy}{dx} = f(x, y)$
- **편미분방정식 (PDE):** 변수가 여러 개 → $\frac{\partial u}{\partial t} = k\frac{\partial^2 u}{\partial x^2}$ (열 방정식)

해법:
- **변수분리법:** $\frac{dy}{dx} = g(x)h(y)$ → $\frac{dy}{h(y)} = g(x)dx$로 분리 후 양변 적분
- **1차 선형:** $y' + P(x)y = Q(x)$ → 적분인자 $e^{\int P\,dx}$ 활용
- **2차 선형:** $y'' + ay' + by = 0$ → 특성방정식 $r^2 + ar + b = 0$의 근 활용

## 🔍 수식을 단계별로 풀어볼까요?

$$\frac{dy}{dx} = f(x, y)$$

**1단계: 방정식의 의미 이해**
> "함수 $y$의 변화율(도함수)이 $x$와 $y$에 어떻게 의존하는가"를 나타내요.

**2단계: 간단한 예시 — $\frac{dy}{dx} = ky$**
> "변화율이 현재값에 비례!" → 세균이 많을수록 더 빠르게 늘어나는 것과 같아요.

**3단계: 변수분리**
> $\frac{dy}{y} = k\,dx$로 분리하고, 양변을 적분: $\ln|y| = kx + C_1$

**4단계: 풀이 완성**
> $y = Ce^{kx}$! 초기조건 $y(0) = y_0$이면 $C = y_0$이므로 $y = y_0 e^{kx}$.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 방향장을 켜면 각 점에서 함수가 어느 방향으로 변하는지 화살표로 볼 수 있어요. 초기값 $y_0$을 바꾸면 같은 방향장 위에서 다른 경로를 따라가는 것을 관찰해 보세요!
- **관찰 결과:** 같은 미분방정식이라도 초기조건이 다르면 완전히 다른 해를 가져요! 방향장은 "가능한 모든 해의 지도" 역할을 해요. 계수 $k$가 양수면 성장, 음수면 감쇠!
- **연결 질문:** "자연의 수많은 현상(인구 변화, 온도 변화, 진동)이 모두 미분방정식으로 표현된다면, 수학은 정말 '자연의 언어'가 아닐까요?"

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **미분 (Derivatives)** | ← 핵심 선수 | 미분방정식은 도함수가 포함된 방정식! |
| **적분 (Integrals)** | ← 핵심 도구 | 미분방정식을 풀 때 적분이 필수! |
| **지수함수 (Exponential)** | ↔ 관련 개념 | $y' = ky$의 해가 지수함수! |
| **사인 함수 (Sine Wave)** | ↔ 관련 개념 | $y'' = -y$의 해가 사인/코사인 함수! |

## 실생활 활용

- **인구 성장 모델:** $\frac{dP}{dt} = rP(1 - \frac{P}{K})$ (로지스틱 방정식). 환경 수용력을 고려한 인구 성장을 예측해요!
- **방사성 붕괴:** $\frac{dN}{dt} = -\lambda N$ → $N = N_0 e^{-\lambda t}$. 탄소-14 연대 측정의 수학적 기초!
- **스프링 진동:** $m\frac{d^2x}{dt^2} = -kx$ → 해: $x = A\cos(\omega t + \phi)$. 자동차 서스펜션, 지진 감쇠기에 활용!
- **전염병 확산:** SIR 모델은 연립미분방정식! 감염자, 회복자, 면역자의 변화를 예측해요.
- **날씨 예측:** 대기의 온도, 압력, 습도 변화를 편미분방정식으로 모델링해요.
