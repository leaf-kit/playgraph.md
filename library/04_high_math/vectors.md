# 벡터 / Vectors

크기와 방향을 모두 가진 양으로, 화살표로 나타냅니다.

A quantity with both magnitude and direction.

$$\vec{v} = (v_x, v_y)$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

벡터는 **"어디로 얼마나 가야 하는지"** 를 알려주는 화살표예요!

보물 지도를 생각해 봐요. "동쪽으로 3걸음, 북쪽으로 4걸음 가면 보물이 있다!" 이것이 바로 벡터예요!

- ➡️ 방향: 어느 쪽으로?
- 📏 크기: 얼마나 멀리?

바람도 벡터예요! "북서풍, 초속 10m"는 바람의 방향과 세기를 동시에 알려주죠.

### 📐 중학생 눈높이

벡터 $(v_x, v_y)$는 $x$방향으로 $v_x$, $y$방향으로 $v_y$만큼 이동하라는 뜻이에요.

벡터의 기본 연산:
- **덧셈:** $(3, 2) + (1, 4) = (4, 6)$ → 두 화살표를 이어 붙이기!
- **크기:** $|\vec{v}| = \sqrt{v_x^2 + v_y^2}$ → 피타고라스 정리!
- **스칼라 배:** $2 \times (3, 2) = (6, 4)$ → 같은 방향으로 2배 멀리!

좌표평면 위의 점은 "위치"만 알려주지만, 벡터는 "이동"을 알려주는 거예요!

### 🎓 고등학생 눈높이

벡터는 **선형대수학**의 기본 개념으로, 물리학과 공학의 핵심 도구입니다.

중요 연산:
- **내적 (Dot Product):** $\vec{a} \cdot \vec{b} = a_xb_x + a_yb_y = |\vec{a}||\vec{b}|\cos\theta$
  - 두 벡터의 "유사도" 측정, 수직 판별 ($\vec{a} \cdot \vec{b} = 0$)
- **외적 (Cross Product, 3D):** $\vec{a} \times \vec{b}$ = 두 벡터에 수직인 새 벡터
- **정사영:** 한 벡터를 다른 벡터 위에 투영

벡터 공간의 개념은 행렬, 미분방정식, 양자역학으로 확장돼요.

## 🔍 수식을 단계별로 풀어볼까요?

$$\vec{v} = (v_x, v_y)$$

**1단계: 성분 이해**
> 벡터 $(3, 4)$는 오른쪽으로 3, 위로 4만큼 이동하는 화살표예요.

**2단계: 크기 구하기**
> $|\vec{v}| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$. 직선거리는 5!

**3단계: 방향(각도) 구하기**
> $\theta = \arctan\frac{v_y}{v_x} = \arctan\frac{4}{3} \approx 53.1°$

**4단계: 벡터 덧셈 시각화**
> $(3, 4) + (2, -1) = (5, 3)$. 첫 번째 화살표 끝에서 두 번째 화살표를 이어요!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** x, y 성분을 바꾸면 화살표의 방향과 길이가 함께 변해요. 크기 표시를 켜면 피타고라스 정리가 실시간으로 적용되는 것을 볼 수 있어요!
- **관찰 결과:** 벡터의 크기는 $\sqrt{v_x^2 + v_y^2}$로 항상 0 이상이에요. 같은 크기라도 방향이 다르면 완전히 다른 벡터! 크기와 방향, 두 가지 정보가 모두 중요해요.
- **연결 질문:** "벡터 여러 개를 한꺼번에 다루고 변환하려면 어떻게 해야 할까요? 벡터를 표로 정리하면 어떨까요?" → 이것이 바로 **행렬(Matrices)** 이에요!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **좌표평면 (Coordinate)** | ← 선수 개념 | 좌표평면 위에서 벡터를 나타내요. |
| **삼각함수 (Trigonometric)** | ↔ 관련 개념 | 벡터의 성분 분해에 sin, cos 사용! |
| **행렬 (Matrices)** | → 후속 개념 | 벡터의 변환을 행렬로 표현해요. |
| **복소수 (Complex Numbers)** | ↔ 관련 개념 | 복소수는 2D 벡터와 대응돼요. |

## 실생활 활용

- **바람 방향과 세기:** 일기예보에서 "남서풍 10m/s"는 벡터! 항공기가 바람을 고려해 항로를 계산할 때 벡터 덧셈을 사용해요.
- **물체 운동 방향:** 축구공을 찰 때 힘의 방향과 세기가 벡터예요. 여러 힘이 작용할 때 벡터 합으로 최종 움직임을 예측!
- **항공기 항로:** 비행기의 속도 벡터 + 바람 벡터 = 실제 이동 벡터. 이것으로 정확한 도착 시간을 계산해요.
- **3D 그래픽:** 게임과 영화의 3D 모델링은 모두 벡터! 빛의 방향, 카메라 각도, 물체 이동이 전부 벡터 연산이에요.
