# 단위원 / Unit Circle

단위원은 반지름이 1인 원으로, 삼각함수의 핵심 개념입니다.

원 위의 점 P의 좌표는:

$$P(\theta) = (\cos\theta, \sin\theta)$$

이때 항상 다음이 성립합니다:

$$\cos^2\theta + \sin^2\theta = 1$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

단위원은 **반지름이 딱 1인 특별한 원**이에요!

시계를 상상해 봐요. 시계 바늘 끝이 원 위를 빙글빙글 돌잖아요? 그 바늘의 길이가 딱 1이면 단위원이에요!

- 🕐 바늘이 3시 방향이면 → 오른쪽 끝 (1, 0)
- 🕛 바늘이 12시 방향이면 → 꼭대기 (0, 1)
- 🕘 바늘이 9시 방향이면 → 왼쪽 끝 (-1, 0)

바늘 끝의 가로 위치가 cos, 세로 위치가 sin이에요!

### 📐 중학생 눈높이

단위원에서 각도 $\theta$만큼 회전한 점의 좌표가 $(\cos\theta, \sin\theta)$예요.

피타고라스 정리 기억나죠? 원 위의 점에서 $x$축에 수선을 내리면 직각삼각형이 만들어져요:
- 빗변 = 반지름 = 1
- 밑변 = $\cos\theta$
- 높이 = $\sin\theta$

그래서 $\cos^2\theta + \sin^2\theta = 1$이 항상 성립! 이것이 삼각함수에서 가장 중요한 항등식이에요.

### 🎓 고등학생 눈높이

단위원은 삼각함수를 **각도의 제한 없이** 확장하는 도구입니다. 직각삼각형에서는 $0° < \theta < 90°$에서만 정의되지만, 단위원을 사용하면 모든 실수 $\theta$에 대해 $\sin\theta$와 $\cos\theta$를 정의할 수 있어요.

핵심 성질:
- **주기성:** $\sin(\theta + 2\pi) = \sin\theta$
- **대칭성:** $\cos(-\theta) = \cos\theta$ (우함수), $\sin(-\theta) = -\sin\theta$ (기함수)
- **오일러 공식과의 연결:** $e^{i\theta} = \cos\theta + i\sin\theta$

## 🔍 수식을 단계별로 풀어볼까요?

$$P(\theta) = (\cos\theta, \sin\theta)$$

**1단계: 원점에서 출발**
> 원점 (0, 0)에 원의 중심이 있고, 반지름이 1인 원을 그려요.

**2단계: 시작점 확인**
> 양의 $x$축 위의 점 (1, 0)이 시작점! 여기서부터 반시계 방향으로 회전해요.

**3단계: $\theta$만큼 회전**
> $\theta = \frac{\pi}{4}$ (45도)만큼 회전하면 점의 위치는 $(\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})$

**4단계: 좌표 읽기**
> 도착한 점의 $x$좌표가 $\cos\theta$, $y$좌표가 $\sin\theta$! 피타고라스 정리로 $x^2 + y^2 = 1$이 확인돼요.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 자동 회전을 켜고 투영선을 보면, $x$축 투영(cos)과 $y$축 투영(sin)이 파동처럼 움직이는 것을 볼 수 있어요! 이것이 바로 사인파와 코사인파의 탄생이에요.
- **관찰 결과:** 단위원의 회전 운동은 사인파와 코사인파를 동시에 만들어내요. cos는 sin보다 $\frac{\pi}{2}$만큼 앞서 있고, 이 관계가 $\cos\theta = \sin(\theta + \frac{\pi}{2})$로 표현돼요!
- **연결 질문:** "원 위의 점이 빙글빙글 도는 움직임을 시간에 따라 펼쳐놓으면 어떤 모양이 될까요?" → 이것이 바로 **사인 함수(Sine Wave)** 의 그래프예요!

## 주요 각도

| 각도 (도) | 각도 (라디안) | cos | sin |
|-----------|--------------|-----|-----|
| 0 | 0 | 1 | 0 |
| 30 | $\pi/6$ | $\sqrt{3}/2$ | $1/2$ |
| 45 | $\pi/4$ | $\sqrt{2}/2$ | $\sqrt{2}/2$ |
| 60 | $\pi/3$ | $1/2$ | $\sqrt{3}/2$ |
| 90 | $\pi/2$ | 0 | 1 |

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **피타고라스 정리** | ← 선수 개념 | $\cos^2\theta + \sin^2\theta = 1$은 피타고라스 정리 그 자체! |
| **사인 함수 (Sine Wave)** | → 후속 개념 | 단위원의 회전을 시간 축으로 펼치면 사인파! |
| **삼각함수 (Trigonometric)** | → 후속 개념 | 단위원에서 모든 삼각함수가 정의돼요. |
| **복소수 (Complex Numbers)** | → 심화 개념 | 복소평면의 단위원과 오일러 공식으로 연결! |

## 실생활 활용

- **시계:** 시계 바늘의 끝 위치를 $(\cos\theta, \sin\theta)$로 나타낼 수 있어요. 시간을 각도로 변환하면 바늘 위치를 정확히 계산!
- **회전 운동:** 놀이공원 관람차, 선풍기 날개, 자동차 바퀴 등 회전하는 모든 것이 단위원의 원리를 따라요.
- **GPS 좌표:** 지구 위의 위치를 위도와 경도(각도)로 표현하는 것도 단위원의 확장이에요.
- **게임 개발:** 캐릭터가 원형으로 이동하거나 총알이 퍼져나가는 패턴을 만들 때 단위원을 활용해요.
