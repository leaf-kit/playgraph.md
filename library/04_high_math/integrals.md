# 적분 / Integrals

함수의 그래프와 x축 사이의 넓이를 구하는 연산입니다.

Finding the area under a curve between two points.

$$\int_a^b f(x)\,dx$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

적분은 **"구불구불한 모양의 넓이를 구하는 마법"** 이에요!

직사각형의 넓이는 가로 × 세로로 쉽게 구하죠? 하지만 산 모양이나 파도 모양의 넓이는 어떻게 구할까요?

비밀은 **아주 얇은 직사각형을 잔뜩 쌓는 것**이에요!
- 📏 얇은 직사각형 10개 → 대충 비슷해요
- 📏 100개 → 꽤 정확해져요
- 📏 무한히 많이 → 정확한 넓이!

이렇게 "잘게 쪼개서 다시 합치는 것"이 적분이에요!

### 📐 중학생 눈높이

적분은 미분의 **역연산**이에요!

미분이 "넓이 → 높이(변화율)"라면, 적분은 "높이 → 넓이(총량)"예요.

$f(x) = 2x$의 적분: $\int 2x\,dx = x^2 + C$
→ 확인: $(x^2)' = 2x$ ✓ 미분하면 원래 함수로 돌아와요!

정적분은 구간을 정해서 실제 넓이를 구하는 것:
$$\int_0^3 2x\,dx = [x^2]_0^3 = 9 - 0 = 9$$

### 🎓 고등학생 눈높이

**미적분학의 기본 정리 (Fundamental Theorem of Calculus):**

$F(x)$가 $f(x)$의 부정적분이면:
$$\int_a^b f(x)\,dx = F(b) - F(a)$$

이것은 **미분과 적분이 역연산**임을 증명하는 핵심 정리예요!

기본 적분 공식:
- $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$ ($n \neq -1$)
- $\int \frac{1}{x}\,dx = \ln|x| + C$
- $\int e^x\,dx = e^x + C$
- $\int \sin x\,dx = -\cos x + C$

## 🔍 수식을 단계별로 풀어볼까요?

$$\int_a^b f(x)\,dx$$

**1단계: 적분 구간 $[a, b]$ 확인**
> 넓이를 구할 구간의 시작점 $a$와 끝점 $b$를 확인해요. 예: $\int_0^2 x^2\,dx$에서 구간은 0부터 2.

**2단계: 부정적분(역도함수) 구하기**
> $f(x) = x^2$의 부정적분은 $F(x) = \frac{x^3}{3}$. "미분하면 원래 함수가 되는 것"을 찾아요!

**3단계: 대입해서 빼기**
> $F(b) - F(a) = \frac{2^3}{3} - \frac{0^3}{3} = \frac{8}{3} - 0 = \frac{8}{3}$

**4단계: 의미 해석**
> 이 값은 $y = x^2$ 그래프 아래, $x = 0$에서 $x = 2$까지의 넓이예요! 약 2.67 평방단위!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 리만 합 보기를 켜면 직사각형들이 곡선 아래를 채우는 것을 볼 수 있어요. 직사각형 수를 늘리면 곡선과의 틈이 점점 줄어드는 것을 관찰!
- **관찰 결과:** 직사각형이 무한히 많아지면 정확한 넓이에 수렴해요. 이것이 "리만 합의 극한 = 적분"이라는 개념! 적분 기호 $\int$는 사실 Sum(합)의 S를 늘인 것이에요.
- **연결 질문:** "적분으로 2D 넓이를 구할 수 있다면, 3D 부피도 구할 수 있을까요? 미분이 포함된 방정식은 어떻게 풀까요?" → **미분방정식(Differential Equations)** 으로 이어져요!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **미분 (Derivatives)** | ↔ 역연산 | 미분의 역연산이 적분! 미적분학의 기본 정리! |
| **극한 (Limits)** | ← 선수 개념 | 리만 합의 극한이 적분! |
| **넓이 (Area)** | ← 기반 개념 | 직사각형 넓이에서 곡선 아래 넓이로 확장! |
| **미분방정식 (Differential Eq.)** | → 심화 개념 | 미분방정식을 풀 때 적분이 핵심 도구! |

## 실생활 활용

- **면적 계산:** 불규칙한 땅의 면적, 호수의 넓이 등을 적분으로 정확히 계산해요. 측량사들이 실제로 사용하는 방법!
- **이동 거리 계산:** 속도-시간 그래프 아래의 넓이 = 이동 거리! $\int_0^t v(t)\,dt = $ 총 이동 거리예요.
- **부피 계산:** 회전체의 부피를 적분으로 구해요. 와인 잔, 꽃병 등 곡선을 회전시킨 입체의 부피!
- **에너지 계산:** 물리학에서 일(에너지) = 힘 × 거리. 힘이 변하면 $W = \int F\,dx$로 적분!
- **확률 계산:** 정규분포 곡선 아래의 면적이 확률! $P(a \leq X \leq b) = \int_a^b f(x)\,dx$
