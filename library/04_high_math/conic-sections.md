# 이차곡선 / Conic Sections

원뿔을 잘랐을 때 나타나는 곡선 — 원, 타원, 포물선, 쌍곡선입니다.

Curves formed by intersecting a cone: circle, ellipse, parabola, hyperbola.

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

이차곡선은 **아이스크림 콘을 칼로 자르면 나오는 모양들**이에요!

원뿔 모양의 아이스크림 콘을 상상해 봐요:
- 🔵 가로로 자르면 → **원!**
- 🥚 비스듬히 자르면 → **타원!** (달걀 모양)
- 🏹 옆면과 평행하게 자르면 → **포물선!** (공 던지는 궤적)
- ♾️ 세로로 자르면 → **쌍곡선!** (두 개의 곡선)

같은 원뿔에서 자르는 각도만 바꿔도 전혀 다른 모양이 나와요! 정말 신기하죠?

### 📐 중학생 눈높이

이차곡선은 **$x^2$과 $y^2$ 항이 들어간 이차식**으로 표현돼요:

- **원:** $x^2 + y^2 = r^2$ (계수가 같음)
- **타원:** $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (계수가 다름, 둘 다 +)
- **포물선:** $y = ax^2$ (한쪽만 제곱)
- **쌍곡선:** $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ (하나가 -)

각 곡선에는 **초점(focus)** 이라는 특별한 점이 있어요. 초점과의 거리 관계가 각 곡선의 성질을 결정해요!

### 🎓 고등학생 눈높이

이차곡선의 통합적 정의 — **이심률(eccentricity) $e$**:

초점 $F$까지의 거리와 준선(directrix)까지의 거리의 비:
$$\frac{PF}{Pd} = e$$

- $e = 0$: 원
- $0 < e < 1$: 타원
- $e = 1$: 포물선
- $e > 1$: 쌍곡선

타원의 매개변수 표현: $x = a\cos t$, $y = b\sin t$
쌍곡선의 점근선: $y = \pm\frac{b}{a}x$

## 🔍 수식을 단계별로 풀어볼까요?

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

**1단계: $a$와 $b$ — 반축의 길이**
> 타원의 가로 반지름이 $a$, 세로 반지름이 $b$예요. $a = b$이면 원!

**2단계: 꼭짓점 찾기**
> $(\pm a, 0)$과 $(0, \pm b)$가 타원의 꼭짓점! 이 네 점을 지나는 부드러운 곡선이에요.

**3단계: 초점의 위치**
> $a > b$일 때 초점은 $(\pm c, 0)$, 여기서 $c = \sqrt{a^2 - b^2}$. 초점은 항상 긴 축 위에!

**4단계: 타원의 성질**
> 타원 위의 모든 점에서 두 초점까지의 거리의 합은 항상 $2a$! 이것이 타원의 정의예요.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** $a$와 $b$를 같게 하면 원이 되고, 차이가 클수록 타원이 찌그러져요! 초점 표시를 켜면 $a$와 $b$의 차이에 따라 초점이 중심에서 멀어지는 것을 관찰해 보세요.
- **관찰 결과:** $a = b$일 때 초점이 중심에 합쳐지며 원이 돼요 ($c = 0$). $a$와 $b$의 차이가 클수록 이심률이 1에 가까워지며 타원이 더 길쭉해져요. 이심률이 곡선의 "찌그러진 정도"를 나타내요!
- **연결 질문:** "행성의 궤도가 타원이라면, 이심률이 큰 행성은 태양에 아주 가까이 갔다가 멀어지겠죠? 혜성의 궤도는 어떤 이차곡선일까요?" → 천문학과 물리학의 세계로!

## 실생활 활용

- **행성 궤도:** 케플러의 제1법칙 — 행성은 태양을 초점으로 하는 타원 궤도를 그려요! 지구의 이심률은 약 0.017(거의 원에 가까움).
- **위성 안테나:** 파라볼라(포물선) 안테나는 전파를 초점에 모아요. 위성방송 수신, 레이더의 핵심 원리!
- **아치 다리 설계:** 포물선과 현수선 모양은 하중을 균등하게 분산시켜 구조적으로 안정적이에요.
- **속삭임의 방:** 타원형 돔 건축물에서 한 초점에서 속삭이면 다른 초점에서 들려요! 소리가 타원의 성질을 따라 반사되기 때문.
