# 이차곡선 / Conic Sections

원뿔을 잘랐을 때 나타나는 곡선 — 원, 타원, 포물선, 쌍곡선입니다.

Curves formed by intersecting a cone: circle, ellipse, parabola, hyperbola.

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$
