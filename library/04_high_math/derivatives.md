# 미분 / Derivatives

함수의 순간 변화율을 구하는 연산입니다.

The instantaneous rate of change of a function.

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

미분은 **"지금 이 순간 얼마나 빠르게 변하고 있니?"** 를 알아내는 마법이에요!

상상해 보세요. 자전거를 타고 언덕길을 달리고 있어요. 언덕이 갑자기 가파라지면 힘들어지죠? 미분은 바로 **"지금 내가 서 있는 곳이 얼마나 가파른지"** 를 숫자로 알려주는 거예요.

- 🚴 평평한 길 → 미분값 = 0 (편안해요!)
- ⛰️ 오르막길 → 미분값 > 0 (올라가고 있어요!)
- 🎿 내리막길 → 미분값 < 0 (내려가고 있어요!)

식물이 자라는 것도 생각해 볼 수 있어요. 해바라기가 하루에 3cm 자란다면, 그건 해바라기의 "성장 미분값"이 3이라는 뜻이에요!

### 📐 중학생 눈높이

중학교에서 배운 **기울기** 기억나요? $y = 2x + 1$에서 기울기는 항상 2였죠?

하지만 **곡선**은 어떨까요? $y = x^2$ 같은 곡선은 위치마다 기울기가 달라요! 미분은 바로 **곡선 위 임의의 점에서의 순간 기울기**를 구하는 도구예요.

직선의 기울기는 이렇게 구했죠:
$$\text{기울기} = \frac{\text{y의 변화량}}{\text{x의 변화량}} = \frac{\Delta y}{\Delta x}$$

미분은 이 아이디어를 **극한**으로 확장한 거예요. 두 점 사이의 거리를 0에 가깝게 줄이면, **접선의 기울기**가 됩니다!

### 🎓 고등학생 눈높이

미분은 함수 $f(x)$의 **도함수** $f'(x)$를 구하는 과정이에요. 도함수는 원래 함수의 각 점에서의 순간 변화율을 나타내는 새로운 함수입니다.

핵심 공식인 **미분의 정의**를 엄밀하게 살펴볼게요:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

이 식은 **평균변화율의 극한**으로 순간변화율을 정의합니다. 기하학적으로는 **할선(secant line)이 접선(tangent line)으로 수렴**하는 과정이에요.

기본 미분 공식들:
- **멱함수:** $(x^n)' = nx^{n-1}$
- **합의 미분:** $(f+g)' = f' + g'$
- **곱의 미분:** $(fg)' = f'g + fg'$
- **연쇄 법칙:** $(f(g(x)))' = f'(g(x)) \cdot g'(x)$

## 🔍 수식을 단계별로 풀어볼까요?

미분의 핵심 공식을 하나하나 뜯어볼게요. 마치 선생님이 칠판에 천천히 적어주듯이요!

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

---

**1단계: $f(a)$ — 출발점 확인하기**

> 안녕! 먼저 우리가 서 있는 시작점 $a$에서의 높이를 확인해보자. 여기가 우리의 출발점이야.

함수 $f(x) = x^2$을 예로 들어볼게요. $a = 3$이면:
$$f(3) = 3^2 = 9$$
우리는 지금 높이 9인 곳에 서 있어요! 이곳이 바로 우리의 시작점이에요.

---

**2단계: $a + h$ — 아주 조금 옆으로 걸어가기**

> 이제 옆으로 아주 조금, $h$만큼만 걸어가 볼까? 그럼 새로운 위치 $a+h$에 도착하게 돼.

$h = 0.1$이라면, 새로운 위치는:
$$a + h = 3 + 0.1 = 3.1$$
아주 조금만 옆으로 이동했어요. 이 $h$를 나중에 0에 가깝게 줄여나갈 거예요!

---

**3단계: $f(a+h) - f(a)$ — 높이 변화 측정하기**

> 우리가 옆으로 이동하는 동안 높이는 얼마나 변했을까? 나중 높이에서 처음 높이를 빼면 '키가 얼마나 컸는지' 알 수 있어.

새로운 위치에서의 높이를 계산하면:
$$f(3.1) = (3.1)^2 = 9.61$$
따라서 높이 변화는:
$$f(3.1) - f(3) = 9.61 - 9 = 0.61$$
$0.1$만큼 옆으로 갔더니 높이가 $0.61$만큼 올라갔네요!

---

**4단계: 전체 식 ($\div h$) — 기울기 구하기**

> 자, 이제 우리가 이동한 거리 $h$로 그 변화량을 나눠보자. 그러면 우리가 얼마나 가파른 언덕을 올랐는지 '기울기'를 알 수 있단다!

$$\frac{f(3.1) - f(3)}{0.1} = \frac{0.61}{0.1} = 6.1$$

$h$를 점점 줄여보면:
| $h$ | $\frac{f(3+h)-f(3)}{h}$ |
|-----|--------------------------|
| 0.1 | 6.1 |
| 0.01 | 6.01 |
| 0.001 | 6.001 |
| 0.0001 | 6.0001 |

$h \to 0$이면 값이 **6**에 다가가죠! 그래서 $f'(3) = 6$이에요.

---

**일반화하면:**

$$f'(x) = \lim_{h \to 0} \frac{(x+h)^2 - x^2}{h} = \lim_{h \to 0} \frac{x^2 + 2xh + h^2 - x^2}{h} = \lim_{h \to 0} \frac{2xh + h^2}{h} = \lim_{h \to 0} (2x + h) = 2x$$

$f(x) = x^2$의 도함수는 $f'(x) = 2x$! $x=3$을 대입하면 $f'(3) = 6$으로, 위의 결과와 일치해요!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 차수 n을 바꾸면 접선의 기울기가 달라지고, x 위치를 움직이면 같은 곡선에서도 기울기가 계속 변하는 것을 볼 수 있어요. 특히 꼭짓점(x=0)에서 접선이 수평이 되는 걸 관찰해 보세요!
- **관찰 결과:** 곡선 위의 모든 점은 저마다 다른 기울기를 가져요. 미분은 이 "점마다 다른 기울기"를 하나의 함수로 표현하는 강력한 도구입니다. $f(x) = x^n$이면 $f'(x) = nx^{n-1}$이라는 아름다운 규칙이 있어요!
- **연결 질문:** "미분이 '쪼개는' 것이라면, 반대로 '모으는' 것은 무엇일까요? 접선 아래의 면적을 모두 합치면 어떤 값이 될까요?" → 이것이 바로 **적분(Integrals)** 으로 이어집니다!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **극한 (Limits)** | ← 선수 개념 | 미분의 정의 자체가 극한을 사용해요. 극한을 이해해야 미분을 이해할 수 있어요! |
| **적분 (Integrals)** | → 후속 개념 | 미분의 역연산이 적분이에요. 미적분학의 기본 정리로 연결됩니다. |
| **다항함수 (Polynomial)** | ↔ 관련 개념 | 다항함수의 미분은 멱함수 미분 규칙으로 쉽게 구할 수 있어요. |
| **이차함수 (Quadratic)** | ↔ 관련 개념 | 이차함수의 꼭짓점은 미분값이 0인 점! 최댓값/최솟값을 구하는 핵심이에요. |
| **미분방정식 (Differential Eq.)** | → 심화 개념 | 미분을 포함한 방정식을 풀면 자연 현상을 모델링할 수 있어요. |

## 실생활 활용

- **속도 = 위치의 미분:** 자동차 네비게이션이 "현재 속도 80km/h"를 표시하는 것은 위치 함수를 미분한 값이에요. GPS가 매 순간 위치 변화를 계산해서 속도를 알려주는 거죠!
- **가속도 = 속도의 미분:** 놀이공원 롤러코스터에서 느끼는 짜릿한 중력은 가속도, 즉 속도를 한 번 더 미분한 값이에요. 급하강할 때 가속도가 커지면 더 무섭게 느껴져요!
- **최대/최소값 구하기:** 택배 상자를 만들 때, 종이 한 장으로 가장 큰 부피의 상자를 만들려면? 부피 함수를 미분해서 0이 되는 점을 찾으면 됩니다!
- **경제학의 한계비용:** 물건을 하나 더 생산할 때 드는 추가 비용(한계비용)은 총비용 함수의 미분이에요. 기업이 최적 생산량을 결정하는 데 미분이 사용돼요.
- **의학의 약물 농도 변화:** 약을 복용한 후 혈중 농도가 최대가 되는 시점을 찾으려면 농도 함수를 미분해서 0이 되는 점을 구해요.
