# 복소수 / Complex Numbers

실수와 허수의 합으로 이루어진 수입니다.

Numbers with a real part and an imaginary part.

$$z = a + bi, \; i^2 = -1$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

복소수는 **"보이지 않는 차원의 숫자"** 예요!

보통 숫자는 수직선 위에 있죠? 1, 2, 3... 하지만 "$-1$의 제곱근은 뭘까?"라는 질문에 답하려면 수직선에서 벗어나야 해요!

마치 게임에서 새로운 세계를 발견하는 것처럼, 수학자들은 **위아래로도 갈 수 있는 새로운 숫자 세계**를 만들었어요! 이것이 복소수 평면이에요.

- ↔️ 가로 방향: 실수 (보통 숫자)
- ↕️ 세로 방향: 허수 (새로운 숫자!)

### 📐 중학생 눈높이

$x^2 + 1 = 0$을 풀면? $x^2 = -1$인데, 어떤 실수를 제곱해도 음수가 될 수 없잖아요!

그래서 수학자들은 $i^2 = -1$인 새로운 수 $i$(허수 단위)를 도입했어요. 복소수 $z = a + bi$에서:
- $a$: 실수부 (가로 위치)
- $b$: 허수부 (세로 위치)

복소수의 연산:
- $(2 + 3i) + (1 + 4i) = 3 + 7i$ (성분별 덧셈)
- $(2 + 3i)(1 + 4i) = 2 + 8i + 3i + 12i^2 = 2 + 11i - 12 = -10 + 11i$

### 🎓 고등학생 눈높이

복소수는 **극형식**으로도 표현할 수 있어요:
$$z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

여기서 $r = |z| = \sqrt{a^2 + b^2}$ (크기), $\theta = \arg(z)$ (편각).

**오일러의 공식** $e^{i\pi} + 1 = 0$은 수학에서 가장 아름다운 공식으로 불려요. 여기에 $e$, $i$, $\pi$, $1$, $0$이라는 수학의 5대 상수가 모두 등장하기 때문이에요!

복소수의 곱셈은 극형식에서 "크기는 곱하고, 각도는 더하는" 연산이에요.

## 🔍 수식을 단계별로 풀어볼까요?

$$z = a + bi, \; i^2 = -1$$

**1단계: 실수부 $a$**
> 복소수의 "가로 위치"예요. 복소평면에서 가로축(실수축) 위의 좌표!

**2단계: 허수부 $b$**
> 복소수의 "세로 위치"예요. 세로축(허수축) 위의 좌표! $i$가 붙어있다는 것만 기억하세요.

**3단계: $i^2 = -1$의 마법**
> $i$를 곱하면 90도 회전! $1 \to i \to -1 \to -i \to 1$로 360도를 돌아와요. 이것이 복소수 곱셈의 핵심!

**4단계: 크기(절댓값) 구하기**
> $|z| = \sqrt{a^2 + b^2}$. 벡터의 크기 구하기와 같아요! $|3 + 4i| = 5$

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 극형식 보기를 켜면 복소수가 원점에서 떨어진 거리(크기)와 양의 실수축과의 각도(편각)로 표현되는 것을 볼 수 있어요! 실수부와 허수부를 바꿔가며 크기와 각도가 어떻게 변하는지 관찰해 보세요.
- **관찰 결과:** 크기가 같은 복소수들은 원점을 중심으로 한 원 위에 놓여요! 복소수의 곱셈은 "원 위에서 회전"하는 것과 같아요. 이것이 단위원과 연결되는 아름다운 관계예요.
- **연결 질문:** "복소수가 2D 벡터처럼 보이는데, 여러 개의 벡터를 한 번에 변환하는 방법은 없을까요?" → **행렬(Matrices)** 이 바로 그 도구예요!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **이차방정식 (Quadratic Eq.)** | ← 선수 개념 | 판별식 < 0일 때 복소수 근이 등장! |
| **벡터 (Vectors)** | ↔ 관련 개념 | 복소수는 2D 벡터와 대응돼요. |
| **단위원 (Unit Circle)** | ↔ 관련 개념 | 오일러 공식으로 단위원과 연결! |
| **행렬 (Matrices)** | → 심화 개념 | 복소수 연산을 행렬로 표현할 수 있어요. |

## 실생활 활용

- **전자공학 교류 회로:** 교류 전류와 전압을 복소수로 표현하면 위상차와 임피던스 계산이 매우 간편해져요. 전기공학에서 가장 많이 쓰이는 수학!
- **양자역학:** 양자역학의 파동함수는 복소수! $\psi(x) = Ae^{ikx}$ 형태로, 입자의 상태를 기술해요.
- **신호 처리:** 디지털 음악, 영상 압축, 통신에서 푸리에 변환은 복소수를 사용해요. 노이즈 캔슬링 이어폰의 핵심 기술!
- **프랙탈 아트:** 만델브로 집합은 복소수의 반복 연산으로 만들어지는 아름다운 수학적 예술이에요!
