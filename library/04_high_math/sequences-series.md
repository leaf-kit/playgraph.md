# 수열 / Sequences & Series

일정한 규칙에 따라 나열된 수의 열입니다.

An ordered list of numbers following a specific pattern.

$$a_n = a_1 + (n-1)d$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

수열은 **숫자들이 줄을 서서 기다리는 것**과 같아요!

놀이공원에서 줄을 설 때, 1번, 2번, 3번... 순서대로 번호표를 받죠? 수열도 마찬가지예요. 숫자들이 **규칙을 가지고 나란히** 서 있어요.

- 🌱 화분을 하루에 하나씩 늘려가면: 1, 2, 3, 4, 5... (매일 1씩 커져요!)
- 🍎 사과를 2개씩 더 쌓으면: 2, 4, 6, 8, 10... (매번 2씩 커져요!)

이렇게 **"다음에 올 숫자를 예측할 수 있는 규칙이 있는 숫자 줄"**이 바로 수열이에요!

### 📐 중학생 눈높이

수열은 **자연수를 입력하면 숫자가 나오는 함수**와 비슷해요!

$a_n$은 "$n$번째에 있는 수"를 뜻해요. 예를 들어 $a_n = 2n + 1$이면:
- $a_1 = 3$, $a_2 = 5$, $a_3 = 7$...

중학교에서 배운 일차함수 $y = mx + b$와 닮았죠? 등차수열의 일반항 $a_n = a_1 + (n-1)d$는 사실 $n$에 대한 일차함수예요! 기울기가 공차 $d$이고, 그래프를 그리면 점들이 직선 위에 놓여요.

### 🎓 고등학생 눈높이

수열은 **정의역이 자연수인 함수** $a: \mathbb{N} \to \mathbb{R}$입니다. 등차수열에서 일반항 공식은:

$$a_n = a_1 + (n-1)d$$

여기서 $a_1$은 첫째항, $d$는 공차(common difference)예요. 수열의 핵심은 **일반항**과 **점화식**의 관계를 이해하는 것입니다:
- 일반항: $a_n = a_1 + (n-1)d$ (바로 $n$번째 항을 계산)
- 점화식: $a_{n+1} = a_n + d$ (이전 항에서 다음 항을 유도)

수열은 급수, 극한, 미적분의 기초가 되는 핵심 개념이에요.

## 🔍 수식을 단계별로 풀어볼까요?

$$a_n = a_1 + (n-1)d$$

이 공식을 따뜻하게 풀어볼게요!

**1단계: $a_1$ — 첫째항 확인**
> 가장 먼저, 줄의 맨 앞에 서 있는 첫 번째 수를 확인해요. 예를 들어 첫째항이 3이면, $a_1 = 3$이에요.

**2단계: $d$ — 규칙(공차) 찾기**
> 다음 수로 갈 때마다 얼마씩 변하는지 살펴봐요. 매번 5씩 커지면 $d = 5$예요.

**3단계: $(n-1)$ — 몇 번 점프했는지 세기**
> $n$번째 항까지 가려면 첫째항에서 $(n-1)$번 점프해야 해요. 5번째 항이면 4번 점프!

**4단계: 전체 합치기**
> 첫째항 + (점프 횟수 × 한 번에 가는 거리) = $n$번째 항!
> $a_5 = 3 + (5-1) \times 5 = 3 + 20 = 23$

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 첫째항과 공차를 바꾸면 수열의 점들이 직선 위에서 움직이는 것을 관찰할 수 있어요. 공차가 양수면 오른쪽 위로, 음수면 오른쪽 아래로 점들이 나열돼요.
- **관찰 결과:** 등차수열의 그래프는 항상 직선 위의 점들이에요. 공차 $d$가 직선의 기울기 역할을 하고, 첫째항 $a_1$이 시작점을 결정해요!
- **연결 질문:** "이 점들을 모두 더하면 어떤 값이 될까요? 항의 수가 많아지면 합도 끝없이 커질까요?" → 이것이 바로 **등차급수(Arithmetic Series)** 로 이어집니다!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **패턴 (Patterns)** | ← 선수 개념 | 규칙 찾기에서 수열의 개념이 시작돼요. |
| **등차급수 (Arithmetic Series)** | → 후속 개념 | 수열의 항들을 모두 더하면 급수가 됩니다! |
| **등비급수 (Geometric Series)** | → 후속 개념 | 곱하기 규칙으로 확장된 수열이에요. |
| **극한 (Limits)** | → 심화 개념 | 수열이 한없이 다가가는 값이 극한이에요. |

## 실생활 활용

- **급여 인상 패턴:** 매년 200만원씩 연봉이 오른다면, 연봉은 등차수열을 이뤄요. 10년 후 연봉을 바로 계산할 수 있죠!
- **좌석 배열:** 공연장에서 앞줄은 10석, 뒤로 갈수록 2석씩 늘어난다면 $n$번째 줄의 좌석 수는 $a_n = 10 + 2(n-1)$이에요.
- **적금 이자:** 매달 일정 금액을 넣는 적금에서, 각 달에 쌓이는 이자는 수열의 패턴을 따라요.
- **계단 오르기:** 계단을 한 칸씩 올라갈 때 높이 변화는 등차수열! 총 올라간 높이를 계산하려면 급수가 필요해요.
