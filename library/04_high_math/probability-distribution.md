# 확률분포 / Probability Distribution

확률 변수가 취할 수 있는 값과 그 확률의 대응 관계입니다.

The mathematical function that gives the probabilities of occurrence for different outcomes.

$$P(X = x) = f(x), \quad \sum f(x) = 1$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

확률분포는 **"어떤 일이 얼마나 자주 일어나는지를 그림으로 그린 것"** 이에요!

주사위를 100번 던진다고 생각해 봐요:
- 🎲 1이 나올 횟수: 약 17번
- 🎲 2가 나올 횟수: 약 17번
- 🎲 ... 모든 숫자가 비슷하게!

이것을 막대그래프로 그리면 모든 막대가 비슷한 높이예요. 하지만 주사위 2개의 합은? 7이 가장 많이 나오고, 산 모양이 돼요! 이런 "결과별 빈도 그림"이 확률분포예요.

### 📐 중학생 눈높이

확률분포는 **확률변수 $X$가 각 값을 가질 확률을 모아놓은 것**이에요.

핵심 규칙:
- 모든 확률은 0 이상: $P(X = x) \geq 0$
- 모든 확률의 합은 1: $\sum P(X = x) = 1$

기대값(평균): $E(X) = \sum x \cdot P(X = x)$
→ "평균적으로 어떤 값이 나올까?"를 알려줘요.

분산: $V(X) = E(X^2) - [E(X)]^2$
→ "결과가 얼마나 흩어져 있을까?"를 알려줘요.

### 🎓 고등학생 눈높이

주요 확률분포:
- **이항분포** $B(n, p)$: $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$
- **정규분포** $N(\mu, \sigma^2)$: $f(x) = \frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

정규분포의 핵심 성질 (68-95-99.7 법칙):
- $\mu \pm 1\sigma$: 데이터의 약 68%
- $\mu \pm 2\sigma$: 데이터의 약 95%
- $\mu \pm 3\sigma$: 데이터의 약 99.7%

$n$이 충분히 크면 이항분포가 정규분포에 수렴 (중심극한정리)!

## 🔍 수식을 단계별로 풀어볼까요?

$$P(X = x) = f(x), \quad \sum f(x) = 1$$

**1단계: 확률변수 $X$ 정의**
> 실험의 결과를 숫자로 바꿔요. 주사위 눈의 합, 맞춘 문제 수, 키, 무게 등!

**2단계: 각 값의 확률 구하기**
> 각 결과가 나올 확률을 구해요. 공정한 주사위면 각 눈이 $\frac{1}{6}$!

**3단계: 합 = 1 확인**
> 모든 가능한 결과의 확률을 더하면 반드시 1! (뭔가는 반드시 일어나니까요!)

**4단계: 기대값과 분산 계산**
> 기대값 = 가중평균. 분산 = 얼마나 퍼져있는지. 이 두 값으로 분포를 요약!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 평균을 바꾸면 종 모양 곡선이 좌우로 이동하고, 표준편차를 바꾸면 곡선이 넓어지거나 좁아져요. 면적 표시를 켜면 $\mu \pm \sigma$ 범위에 약 68%가 들어가는 것을 확인!
- **관찰 결과:** 정규분포는 평균과 표준편차 두 가지 값만으로 완전히 결정돼요! 표준편차가 작으면 평균 근처에 데이터가 몰리고, 크면 넓게 퍼져요.
- **연결 질문:** "정규분포 곡선 아래의 면적이 확률인데, 곡선 아래 면적을 정확히 구하려면 어떤 수학 도구가 필요할까요?" → 바로 **적분(Integrals)** 이에요!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **확률 기초 (Probability)** | ← 선수 개념 | 확률의 개념이 분포로 확장! |
| **이항정리 (Binomial)** | ← 관련 개념 | 이항분포의 계수가 이항계수! |
| **적분 (Integrals)** | → 심화 개념 | 연속확률분포의 확률 = 적분! |
| **순열과 조합 (P&C)** | ← 선수 개념 | 경우의 수로 확률을 계산! |

## 실생활 활용

- **시험 점수 분포:** 수능 성적은 정규분포를 따라요. 표준점수와 백분위는 정규분포에서 계산! 상위 2.28%가 표준편차 2 이상이에요.
- **품질 관리 (6시그마):** 제조업에서 불량률을 $\mu \pm 6\sigma$ 안에 넣는 것이 목표! 100만 개 중 3.4개 이하의 불량!
- **주식 수익률 분석:** 주가 변동을 정규분포로 모델링하고, 위험도(VaR)를 계산해요. 투자의 리스크 관리!
- **여론조사:** "오차범위 ±3%p, 신뢰수준 95%"는 정규분포의 $\mu \pm 2\sigma$에서 나오는 거예요!
