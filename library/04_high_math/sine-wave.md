# 사인 함수 / Sine Wave

사인 함수는 주기적으로 반복되는 파동을 나타내는 가장 기본적인 삼각함수입니다.

$$y = A \sin(Bx + C) + D$$

- **A**: 진폭 (Amplitude) — 파동의 높이를 결정합니다
- **B**: 주파수 (Frequency) — 파동이 얼마나 빠르게 반복되는지 결정합니다
- **C**: 위상 이동 (Phase Shift) — 그래프를 좌우로 이동시킵니다
- **D**: 수직 이동 (Vertical Shift) — 그래프를 상하로 이동시킵니다

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

사인 함수는 **바다의 파도**와 같아요!

해변에서 파도를 본 적 있죠? 올라갔다가 내려갔다가를 계속 반복해요. 그 모양을 그래프로 그리면 사인 함수가 돼요!

- 🌊 파도가 높으면 → 진폭(A)이 큰 거예요!
- 🌊 파도가 빠르면 → 주파수(B)가 큰 거예요!
- 🌊 파도가 밀려오는 시점이 다르면 → 위상(C)이 다른 거예요!

그네 타기도 생각해 볼 수 있어요. 앞으로 갔다가 뒤로 갔다가... 이 움직임도 사인 함수예요!

### 📐 중학생 눈높이

단위원에서 점이 빙글빙글 돌 때, 그 점의 $y$좌표(높이)를 시간에 따라 그래프로 그리면 사인파가 나와요!

$y = A \sin(Bx + C) + D$에서 각 값의 역할:
- $A$: 파동의 최고점과 최저점의 차이의 절반 (진폭)
- 주기 = $\frac{2\pi}{B}$: 파동이 한 번 반복되는 데 걸리는 거리
- $-\frac{C}{B}$: 그래프가 좌우로 이동한 거리
- $D$: 그래프의 중심선 높이

### 🎓 고등학생 눈높이

사인 함수는 **주기함수의 기본 구성 요소**입니다. 푸리에 분석에 따르면, **모든 주기함수는 사인파와 코사인파의 합**으로 표현할 수 있어요!

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left(a_n\cos(nx) + b_n\sin(nx)\right)$$

이것이 **푸리에 급수**이고, 현대 신호 처리, 음향학, 영상 압축의 수학적 기초입니다.

사인 함수의 미분: $(\sin x)' = \cos x$, 적분: $\int \sin x\,dx = -\cos x + C$

## 🔍 수식을 단계별로 풀어볼까요?

$$y = A \sin(Bx + C) + D$$

**1단계: 진폭 $A$ — 파도의 높이**
> 파도가 중심선에서 얼마나 높이 올라가고 낮게 내려가는지! $A = 3$이면 중심에서 위아래로 3만큼 움직여요.

**2단계: $B$ — 파도의 빠르기**
> $B$가 클수록 파도가 빈번하게 반복돼요. 주기 = $\frac{2\pi}{B}$이므로, $B = 2$면 주기가 $\pi$로 줄어들어요!

**3단계: $C$ — 파도의 출발 시점**
> $C > 0$이면 그래프가 왼쪽으로, $C < 0$이면 오른쪽으로 이동해요. 파도가 일찍 오거나 늦게 오는 거예요!

**4단계: $D$ — 파도의 기준선**
> 전체 그래프를 위아래로 옮겨요. 수면의 기본 높이를 바꾸는 것과 같아요.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 진폭을 키우면 파동이 더 높아지고, 주파수를 키우면 파동이 더 빽빽해져요. 위상을 바꾸면 파동이 좌우로 미끄러지듯 이동하는 것을 관찰해 보세요!
- **관찰 결과:** 사인파의 네 가지 매개변수(A, B, C, D)는 각각 독립적으로 파동의 다른 특성을 조절해요. 이것이 소리, 빛, 전파 등 모든 파동 현상을 수학적으로 표현하는 핵심이에요!
- **연결 질문:** "사인파와 코사인파를 합치면 어떤 새로운 파동이 만들어질까요? 두 파동이 만나면 더 강해지기도 하고 약해지기도 할까요?" → **삼각함수(Trigonometric Functions)** 에서 합성을 배워요!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **단위원 (Unit Circle)** | ← 선수 개념 | 단위원의 회전을 시간에 따라 펼치면 사인파! |
| **삼각함수 (Trigonometric)** | ↔ 관련 개념 | sin, cos, tan의 관계를 다루어요. |
| **미분 (Derivatives)** | → 심화 개념 | $(\sin x)' = \cos x$라는 아름다운 관계! |
| **미분방정식 (Differential Eq.)** | → 심화 개념 | $y'' = -y$의 해가 바로 사인함수예요! |

## 실생활 속 사인 함수

사인 함수는 다양한 자연 현상에서 나타납니다:

- **음파:** 소리는 공기의 압력 변화가 사인파 형태로 전달됩니다. 피아노의 '라' 음은 440Hz(초당 440번 반복)의 사인파!
- **빛:** 전자기파는 사인 함수로 표현됩니다. 빛의 색깔은 사인파의 주파수에 따라 결정돼요.
- **조수:** 바다의 밀물과 썰물은 사인 함수를 따릅니다. 약 12시간 주기로 반복돼요.
- **진자 운동:** 추의 왕복 운동은 사인 함수로 근사할 수 있습니다. 그네, 시계추 등이 모두 이에 해당해요.
- **심전도(ECG):** 심장 박동도 주기적인 파형! 사인파의 합성으로 분석할 수 있어요.
