# 극한 / Limits

x가 특정 값에 한없이 가까워질 때 함수값이 다가가는 값입니다.

The value a function approaches as the input approaches a given value.

$$\lim_{x \to a} f(x) = L$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

극한은 **"도착하지는 않지만 점점 가까이 다가가는 것"** 이에요!

방 건너편에 있는 강아지한테 걸어간다고 상상해 봐요. 남은 거리의 절반만큼만 갈 수 있다면:
- 🐕 처음: 8m 떨어져 있어요
- 한 발짝: 4m로 줄었어요
- 또 한 발짝: 2m → 1m → 0.5m → 0.25m...

강아지한테 절대 "도착"하지는 못하지만, **한없이 가까워져요**! 이 "다가가는 값"이 극한이에요.

### 📐 중학생 눈높이

$f(x) = \frac{x^2 - 1}{x - 1}$에서 $x = 1$을 넣으면? $\frac{0}{0}$으로 정의가 안 돼요!

하지만 $x$가 1에 **가까이** 가면 어떤 값에 다가갈까요?
$$\frac{x^2 - 1}{x - 1} = \frac{(x+1)(x-1)}{x-1} = x + 1$$

$x \to 1$이면 $x + 1 \to 2$. 그래서 $\lim_{x \to 1}\frac{x^2-1}{x-1} = 2$!

함수가 그 점에서 정의되지 않아도, 극한은 존재할 수 있어요. 이것이 극한의 핵심!

### 🎓 고등학생 눈높이

극한의 엄밀한 정의 ($\epsilon$-$\delta$ 정의):
$$\lim_{x \to a} f(x) = L \;\Leftrightarrow\; \forall \epsilon > 0, \exists \delta > 0 : 0 < |x-a| < \delta \Rightarrow |f(x)-L| < \epsilon$$

핵심 극한값:
- $\lim_{x \to 0}\frac{\sin x}{x} = 1$
- $\lim_{x \to \infty}(1 + \frac{1}{x})^x = e$
- $\lim_{x \to 0}\frac{e^x - 1}{x} = 1$

극한은 미분, 적분, 급수의 수렴성 등 해석학의 모든 개념의 기초입니다.

## 🔍 수식을 단계별로 풀어볼까요?

$$\lim_{x \to a} f(x) = L$$

**1단계: $a$ — 다가가는 목표값**
> $x$가 어디를 향해 가는지 확인! $\lim_{x \to 2}$이면 $x$가 2를 향해 다가가요.

**2단계: 양쪽에서 접근**
> 왼쪽($x < 2$)에서도, 오른쪽($x > 2$)에서도 같은 값에 도달해야 극한이 존재!

**3단계: 대입 시도**
> 먼저 $x = a$를 직접 대입해 봐요. 값이 나오면 그것이 극한! $\frac{0}{0}$이면 변형 필요!

**4단계: 부정형 해결**
> $\frac{0}{0}$이면 인수분해, 유리화, 로피탈 법칙 등으로 변형한 뒤 다시 대입!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 추적 보기를 켜고 접근값을 바꿔보면, 점이 목표를 향해 다가가는 것을 볼 수 있어요. 양쪽에서 접근할 때 같은 값에 도달하는지 관찰해 보세요!
- **관찰 결과:** 극한은 "그 점에서의 함수값"이 아니라 "그 점 근처에서의 경향성"이에요! 함수가 그 점에서 정의되지 않아도 극한은 존재할 수 있어요. 이 미묘한 차이가 해석학의 핵심이에요.
- **연결 질문:** "극한으로 '한없이 가까이 다가가는 것'을 알 수 있다면, 이것을 이용해서 곡선의 기울기를 구할 수 있지 않을까요?" → 이것이 바로 **미분(Derivatives)** 의 탄생이에요!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **수열 (Sequences)** | ← 관련 개념 | 수열의 극한이 함수의 극한으로 확장! |
| **미분 (Derivatives)** | → 핵심 후속 | 미분의 정의 = 극한! |
| **적분 (Integrals)** | → 후속 개념 | 리만 합의 극한 = 적분! |
| **등비급수 (Geometric Series)** | ↔ 관련 개념 | 무한급수의 수렴은 극한으로 판정! |

## 실생활 활용

- **속도의 순간값:** "지금 이 순간의 속도"는 시간 간격을 0으로 보내는 극한! $v = \lim_{\Delta t \to 0}\frac{\Delta s}{\Delta t}$
- **인구 포화 모델:** 인구가 한없이 늘어도 식량 등의 제약으로 어떤 값(환경 수용력)에 수렴해요. $\lim_{t \to \infty} P(t) = K$
- **무한 소수의 극한:** $0.999\ldots = \lim_{n \to \infty}(1 - 10^{-n}) = 1$. 0.999...는 정확히 1이에요!
- **카메라 줌:** 사진을 한없이 확대하면 어떤 점의 색상에 수렴해요. 디지털 이미지의 해상도 극한!
