# 이차함수 / Quadratic Function

그래프가 포물선인 함수로, 꼭짓점과 축을 기준으로 대칭입니다.

A function whose graph is a parabola.

$$y = ax^2 + bx + c$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

이차함수는 **분수대에서 물이 솟아오르는 모양**이에요!

공을 하늘로 던지면 어떻게 될까요? 올라갔다가 다시 내려오죠! 그 모양이 바로 포물선이고, 이차함수의 그래프예요.

- ⛲ 분수대의 물줄기 → 포물선!
- 🏀 농구공 슛 → 포물선!
- 🌈 무지개 모양 → 포물선과 비슷해요!

$a$가 양수면 웃는 입 모양(U), 음수면 찡그린 입 모양(∩)이에요!

### 📐 중학생 눈높이

이차함수 $y = ax^2 + bx + c$에서 중요한 것은 **꼭짓점**과 **대칭축**이에요!

꼭짓점 좌표: $\left(-\frac{b}{2a}, f\left(-\frac{b}{2a}\right)\right)$

표준형 $y = a(x-p)^2 + q$로 변환하면:
- $(p, q)$가 꼭짓점
- $x = p$가 대칭축

이차함수는 일차함수 다음으로 만나는 곡선이에요. 직선이 "일정한 변화"를 나타낸다면, 포물선은 "변화가 변하는 것"을 나타내요!

### 🎓 고등학생 눈높이

이차함수의 세 가지 표현:
- **일반형:** $y = ax^2 + bx + c$ → $y$절편과 판별식 파악
- **표준형:** $y = a(x-p)^2 + q$ → 꼭짓점과 대칭축 파악
- **인수분해형:** $y = a(x-\alpha)(x-\beta)$ → 근(x절편) 파악

판별식 $D = b^2 - 4ac$에 따라:
- $D > 0$: $x$축과 두 점에서 만남
- $D = 0$: $x$축에 접함
- $D < 0$: $x$축과 만나지 않음

## 🔍 수식을 단계별로 풀어볼까요?

$$y = ax^2 + bx + c$$

**1단계: 계수 $a$의 역할**
> $a$는 포물선의 "입 벌림 정도"를 결정해요. $|a|$가 크면 좁고, 작으면 넓어요. $a > 0$이면 위로 볼록(U), $a < 0$이면 아래로 볼록(∩)!

**2단계: 꼭짓점 찾기**
> 대칭축은 $x = -\frac{b}{2a}$. 이 값을 원래 식에 대입하면 꼭짓점의 $y$좌표를 구할 수 있어요!

**3단계: $y$절편 확인**
> $x = 0$을 대입하면 $y = c$. 그래프가 $y$축과 만나는 점은 항상 $(0, c)$예요.

**4단계: 대칭 이해하기**
> 꼭짓점을 기준으로 좌우가 완벽하게 대칭! 이 대칭성이 이차함수의 가장 아름다운 성질이에요.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 계수 $a$를 양수에서 음수로 바꾸면 포물선이 뒤집혀요! $b$를 바꾸면 꼭짓점이 좌우로 이동하고, $c$를 바꾸면 위아래로 이동하는 것을 관찰해 보세요.
- **관찰 결과:** 세 계수 $a$, $b$, $c$ 각각이 포물선의 다른 특성(방향/폭, 위치, 높이)을 결정해요. 이 관계를 이해하면 원하는 모양의 포물선을 자유롭게 그릴 수 있어요!
- **연결 질문:** "포물선의 꼭짓점에서 기울기가 0이라는 것을 어떻게 정확히 증명할 수 있을까요?" → **미분(Derivatives)** 으로 $y' = 2ax + b = 0$을 풀면 돼요!

## 🔗 개념 연결 고리

| 연결 개념 | 관계 | 설명 |
|-----------|------|------|
| **일차함수 (Linear)** | ← 선수 개념 | 직선에서 곡선으로의 첫 도약! |
| **다항함수 (Polynomial)** | → 확장 개념 | 이차함수는 2차 다항함수의 특수한 경우예요. |
| **미분 (Derivatives)** | → 심화 개념 | 꼭짓점은 미분값이 0인 점! |
| **이차곡선 (Conic Sections)** | → 심화 개념 | 포물선은 원뿔 곡선의 하나예요. |

## 실생활 활용

- **포물선 운동:** 야구공, 농구공, 분수대의 물줄기 궤적이 모두 포물선이에요. 물리학에서 $y = -\frac{1}{2}gt^2 + v_0t + h_0$로 표현해요.
- **다리 구조:** 현수교의 케이블은 포물선 모양! 이 모양이 하중을 가장 효율적으로 분산시켜요.
- **수익 최적화:** 가격을 $x$만큼 올리면 판매량은 줄지만 단가는 올라요. 수익 = 가격 × 판매량은 이차함수가 되고, 꼭짓점이 최대 수익!
- **위성 안테나:** 포물선 모양의 안테나는 전파를 초점에 모아요. 이것이 위성방송의 원리!
