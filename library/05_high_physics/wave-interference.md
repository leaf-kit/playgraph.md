# 파동의 간섭 / Wave Interference

두 파동이 만나서 세기가 강해지거나 약해지는 현상입니다.

When two waves overlap, they combine constructively or destructively.

$$y = y_1 + y_2$$

## 🌟 선생님의 다정한 설명

> 두 파동이 만나면 더 강해지기도 하고, 사라지기도 해요! 이 신기한 현상이 소음 제거 헤드폰의 원리랍니다.

### 🎈 초등학생 눈높이

연못에 돌멩이 두 개를 동시에 던져보세요! 각 돌멩이에서 물결이 퍼져나가다가 **만나는 곳**이 생기죠? 어떤 곳은 물결이 더 커지고, 어떤 곳은 물결이 사라져서 잔잔해져요.

이것이 바로 **간섭**이에요!
- 물결과 물결이 같은 방향으로 합쳐지면 → **더 큰 물결** (보강 간섭)
- 물결과 물결이 반대 방향으로 만나면 → **서로 상쇄** (상쇄 간섭)

소음 제거 헤드폰은 이 원리를 사용해요! 시끄러운 소리와 정반대인 소리를 만들어서 소음을 **없애버리는** 거예요. 정말 신기하지요?

### 📐 중학생 눈높이

두 스피커를 같은 진동수로 울려볼까요? 스피커 앞에서 좌우로 걸어보면, 어떤 위치에서는 소리가 크게 들리고, 어떤 위치에서는 거의 안 들려요!

- **보강 간섭**: 두 파동의 마루와 마루가 만남 → 진폭 2배
- **상쇄 간섭**: 마루와 골이 만남 → 진폭 0 (소리 소멸!)

이것은 경로차로 설명할 수 있어요:
- 경로차 = 파장의 정수배 → 보강 간섭
- 경로차 = 파장의 반정수배 → 상쇄 간섭

### 🎓 고등학생 눈높이

중첩 원리: $y = y_1 + y_2 = A_1\sin(\omega_1 t + \phi_1) + A_2\sin(\omega_2 t + \phi_2)$

같은 진동수, 같은 진폭일 때:
$$y = 2A\cos\left(\frac{\Delta\phi}{2}\right)\sin\left(\omega t + \frac{\phi_1 + \phi_2}{2}\right)$$

- $\Delta\phi = 0$: 완전 보강, 진폭 $2A$
- $\Delta\phi = \pi$: 완전 상쇄, 진폭 $0$

영의 이중 슬릿 실험:
- 밝은 무늬: $d\sin\theta = m\lambda$ ($m = 0, \pm1, \pm2, \ldots$)
- 어두운 무늬: $d\sin\theta = (m + \frac{1}{2})\lambda$

맥놀이(beat): 진동수가 약간 다른 두 파동 → 맥놀이 진동수 $f_{beat} = |f_1 - f_2|$

## 🔍 수식을 단계별로 풀어볼까요?

$y = y_1 + y_2$의 간섭 조건을 단계별로 이해해봅시다.

1. **중첩 원리**
   - 두 파동이 만나면 각 지점의 변위를 단순히 **더합니다**
   - 이것이 성립하는 이유는 파동 방정식이 선형이기 때문

2. **보강 간섭 조건**
   - 두 파원에서의 경로차 = $m\lambda$ (파장의 정수배)
   - $\Delta\phi = 0, 2\pi, 4\pi, \ldots$
   - 결과: 진폭이 최대

3. **상쇄 간섭 조건**
   - 경로차 = $(m + \frac{1}{2})\lambda$
   - $\Delta\phi = \pi, 3\pi, 5\pi, \ldots$
   - 결과: 진폭이 0 (소멸)

4. **예시: 이중 슬릿**
   - 슬릿 간격 0.1 mm, 빛 파장 500 nm, 스크린 거리 1 m
   - 밝은 무늬 간격: $\Delta y = \frac{\lambda L}{d} = \frac{500 \times 10^{-9} \times 1}{0.1 \times 10^{-3}} = 5$ mm

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 두 파동의 진동수를 조절하면 합성파가 실시간으로 그려져요. 진동수가 같으면 안정적인 간섭 무늬가, 약간 다르면 맥놀이 패턴이 나타납니다.
- **관찰 결과:** 두 파동이 완전히 같은 진동수일 때 보강/상쇄 간섭이 명확하게 보이고, 진동수 차이가 클수록 맥놀이가 빨라지는 것을 확인할 수 있어요.
- **연결 질문:** 소음 제거 헤드폰은 모든 소음을 완벽하게 없앨 수 있을까요? 어떤 종류의 소음에 효과적이고, 어떤 소음에는 덜 효과적일까요?

## 실생활 활용

- **소음 제거 헤드폰** — 마이크로 외부 소음을 측정한 뒤, 정반대 위상의 소리를 만들어 상쇄 간섭시킵니다. 특히 일정한 저주파 소음(비행기 엔진 등)에 효과적이에요!
- **악기 화음** — 피아노에서 여러 건반을 동시에 누르면 각 음의 파동이 간섭하여 화음이 만들어져요. 배음 관계에 따라 아름답게 들리거나 불협화음이 됩니다.
- **영의 이중 슬릿 실험** — 빛이 두 개의 좁은 틈을 통과하면 간섭 무늬(밝고 어두운 줄)가 생겨요. 이것이 빛이 파동이라는 결정적 증거였습니다.
- **조율(튜닝)** — 악기를 맞출 때 두 음을 동시에 내면 맥놀이가 들려요. 맥놀이가 사라지면 두 음의 진동수가 같아진 것이므로 조율 완료!
