# 원운동 / Circular Motion

물체가 원형 경로를 따라 일정한 속력으로 회전하는 운동입니다.

Motion of an object along a circular path.

$$a_c = \frac{v^2}{r}$$

## 🌟 선생님의 다정한 설명

> 원운동은 놀이공원에서 시작해서 우주까지 이어지는 아주 멋진 물리 개념이에요!

### 🎈 초등학생 눈높이

놀이공원에서 회전목마를 타 본 적 있지요? 빙글빙글 돌 때 몸이 바깥쪽으로 쏠리는 느낌이 들죠? 그리고 빨리 돌수록 더 세게 쏠려요!

양동이에 물을 담고 빙글빙글 돌려보세요. 거꾸로 되어도 물이 안 쏟아져요! 이건 물이 계속 원을 따라 움직이려는 힘 때문이에요. 이 신기한 힘이 바로 **구심력**이랍니다.

줄에 공을 매달고 돌려보면, 줄을 놓는 순간 공은 동그라미가 아니라 **직선으로 날아가요**. 원래 물체는 직선으로 가고 싶어하는데, 줄이 계속 안쪽으로 당겨주니까 원을 그리는 거예요!

### 📐 중학생 눈높이

원운동을 이해하려면 먼저 **속력**과 **속도**의 차이를 알아야 해요. 원운동에서 속력(빠르기)은 일정하지만, 방향이 계속 바뀌므로 **속도(벡터)**는 계속 변합니다. 속도가 변하면? 가속도가 있다는 뜻이죠!

실험실에서 원형 트랙에 구슬을 굴려보세요. 구슬이 트랙을 벗어나는 순간 **접선 방향**으로 날아가는 것을 관찰할 수 있어요. 이것은 구심력이 사라지면 물체가 관성에 의해 직선 운동하기 때문입니다.

### 🎓 고등학생 눈높이

등속 원운동에서 구심 가속도와 구심력:

$$a_c = \frac{v^2}{r} = \omega^2 r, \quad F_c = m\frac{v^2}{r}$$

여기서 $\omega = \frac{2\pi}{T}$는 각속도, $T$는 주기입니다.

중요한 점은, 구심력은 새로운 종류의 힘이 아니라 원운동을 유발하는 **알짜힘의 역할**이라는 것입니다:
- 행성 궤도: 구심력 = 만유인력
- 자동차 커브: 구심력 = 마찰력
- 줄에 매단 물체: 구심력 = 장력

비등속 원운동에서는 접선 가속도 $a_t = \frac{dv}{dt}$도 추가로 고려해야 합니다.

## 🔍 수식을 단계별로 풀어볼까요?

$a_c = \frac{v^2}{r}$을 단계별로 이해해봅시다.

1. **기호 이해하기**
   - $a_c$: 구심 가속도 (단위: m/s²), 항상 원의 중심을 향함
   - $v$: 물체의 속력 (단위: m/s)
   - $r$: 원의 반지름 (단위: m)

2. **관계 파악하기**
   - 속력 $v$가 2배 → 구심 가속도 4배 (제곱 관계!)
   - 반지름 $r$이 2배 → 구심 가속도 절반

3. **예시 문제**
   - 반지름 3 m, 속력 2 m/s로 원운동하면?
   - $a_c = \frac{2^2}{3} = \frac{4}{3} \approx 1.33$ m/s²

4. **구심력 계산**
   - $F_c = ma_c = m\frac{v^2}{r}$
   - 질량 5 kg일 때: $F_c = 5 \times 1.33 = 6.67$ N

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 반지름과 속력 슬라이더를 조절하면 물체가 원을 따라 움직이는 모습과 함께, 속도 벡터(접선 방향)와 가속도 벡터(중심 방향)가 실시간으로 표시됩니다.
- **관찰 결과:** 속력을 높이면 구심 가속도가 급격히 커지고(제곱 관계), 반지름을 키우면 같은 속력에서도 구심 가속도가 줄어드는 것을 확인할 수 있어요.
- **연결 질문:** 롤러코스터가 루프(loop) 꼭대기에서 사람이 떨어지지 않으려면 최소 속력이 얼마여야 할까요? (힌트: 꼭대기에서 중력이 구심력 역할을 합니다)

## 실생활 활용

- **놀이공원 회전 놀이기구** — 바이킹, 회전목마, 관람차 모두 구심력이 작용합니다. 안전벨트와 바는 필요한 구심력을 제공하는 역할이에요.
- **인공위성 궤도** — 인공위성이 지구 주위를 도는 것은 중력이 구심력 역할을 하기 때문이에요. 궤도 높이에 따라 속력과 주기가 달라집니다.
- **세탁기 탈수** — 빠르게 회전하는 통에서 물은 구멍을 통해 바깥으로 나가고, 옷은 통에 남습니다.
- **자동차 커브 주행** — 커브길에서 마찰력이 구심력이 되는데, 비 오는 날 마찰이 줄면 커브를 돌지 못하고 미끄러지는 이유가 바로 여기에 있어요!
