# 막대그래프 / Bar Graph

자료의 크기를 막대의 길이로 나타낸 그래프입니다.

A chart that uses bars to show data values.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

막대그래프는 숫자를 **막대 길이**로 보여주는 그림이야! 우리 반 친구들이 좋아하는 과일을 조사했다고 생각해봐. 사과 5명, 바나나 8명, 딸기 3명이면, 바나나 막대가 가장 길겠지?

블록을 쌓는 것처럼 숫자만큼 막대를 쌓으면 돼! 막대가 길수록 수가 크고, 짧을수록 수가 작아. 한눈에 비교할 수 있으니까 정말 편리해!

### 📐 중학생 눈높이

막대그래프는 범주형(categorical) 데이터를 시각화하는 기본 도구예요. 가로축에 항목, 세로축에 수량을 배치하죠. 그래프를 그릴 때 축의 눈금 간격을 일정하게 하고, 0부터 시작하는 것이 중요해요 -- 그렇지 않으면 데이터가 왜곡될 수 있거든요.

히스토그램(연속 데이터)과 막대그래프(범주 데이터)의 차이도 알아두면 좋아요!

### 🎓 고등학생 눈높이

막대그래프는 기술통계학(descriptive statistics)의 기본 시각화 도구입니다. 이후 도수분포표, 히스토그램, 상자 수염 그림(box plot) 등으로 확장됩니다. 데이터 시각화에서 시각적 인코딩(visual encoding) 이론에 따르면, 길이(length)는 인간이 가장 정확하게 비교할 수 있는 시각적 속성 중 하나입니다.

## 🔍 수식을 단계별로 풀어볼까요?

막대그래프를 만드는 과정을 단계별로 해봐요!

1. **자료를 모아요.** 조사한 결과를 정리해요. 예: A = 5, B = 8, C = 3
2. **축을 그려요.** 가로축에 항목(A, B, C), 세로축에 숫자(0~10)를 써요.
3. **막대를 그려요.** 각 항목의 값만큼 막대를 쌓아요. B가 가장 길어요!
4. **비교해요.** 막대 길이를 비교하면 어떤 항목이 가장 큰지 한눈에 알 수 있어요!

그래프는 숫자를 "그림"으로 바꿔주는 마법이에요!

```math-anim
type: bar-graph
params:
  value1: { default: 5, min: 0, max: 10, step: 1, label: { kr: "값 A", en: "Value A" } }
  value2: { default: 8, min: 0, max: 10, step: 1, label: { kr: "값 B", en: "Value B" } }
  value3: { default: 3, min: 0, max: 10, step: 1, label: { kr: "값 C", en: "Value C" } }
  animate: { default: true, label: { kr: "애니메이션", en: "Animate" } }
```

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 세 개의 슬라이더로 값을 바꾸면 막대의 높이가 실시간으로 변해요. 애니메이션으로 막대가 자라나는 모습을 볼 수 있어요.
- **관찰 결과:** 값이 클수록 막대가 길어지고, 값이 같으면 막대 높이도 같아요. 세 값의 차이가 클수록 그래프에서 차이가 뚜렷하게 보인다는 것을 알 수 있어요!
- **연결 질문:** "세 값의 평균은 얼마이고, 그래프에서 평균선을 그으면 어디에 위치할까?" -- 이것이 **평균** 개념으로 이어져요!

## 🔗 개념 연결 고리

막대그래프는 자료 정리와 통계의 첫걸음이에요:

- **덧셈**: 각 막대의 값을 더하면 전체 합계를 알 수 있어요.
- **뺄셈**: 막대끼리의 차이를 구하면 비교할 수 있어요.
- **평균**: 모든 값을 더한 뒤 항목 수로 나누면 평균이에요.

## 실생활 활용

- **학급 선호도 조사** -- "우리 반이 좋아하는 급식 메뉴"를 막대그래프로 나타내면 한눈에 인기 메뉴를 알 수 있어요!
- **월별 기온 비교** -- 1월부터 12월까지 평균 기온을 막대로 나타내면 계절 변화가 보여요.
- **판매량 비교** -- 어떤 상품이 가장 많이 팔렸는지 비교할 수 있어요.
- **독서 기록** -- 이번 달에 읽은 책의 수를 친구들과 비교하는 그래프를 만들어봐요.
- **운동 기록** -- 요일별 줄넘기 횟수를 기록하면 어떤 날 가장 많이 했는지 알 수 있어요!
