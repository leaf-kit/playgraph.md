# 수직선 / Number Line

수를 직선 위에 순서대로 나타낸 것입니다.

A visual representation of numbers on a straight line.

$$\leftarrow \cdots -2, -1, 0, 1, 2 \cdots \rightarrow$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

수직선은 숫자들이 줄을 서 있는 거야! 운동장에 길~게 줄이 있다고 상상해봐. 가운데에 0이 서 있고, 오른쪽으로 가면 1, 2, 3... 숫자가 점점 커지고, 왼쪽으로 가면 -1, -2, -3... 숫자가 작아져.

엘리베이터를 타면 1층, 2층, 3층으로 올라가고, 지하 1층, 2층으로 내려가잖아? 그게 바로 수직선이야!

### 📐 중학생 눈높이

수직선은 수의 크기와 순서를 시각적으로 보여주는 도구예요. 오른쪽으로 갈수록 크고, 왼쪽으로 갈수록 작아요. 덧셈은 오른쪽 이동, 뺄셈은 왼쪽 이동으로 이해할 수 있죠.

좌표 개념의 출발점이기도 해요. 수직선 하나가 x축, 여기에 수직인 수직선이 y축이 되어 좌표평면이 만들어진답니다.

### 🎓 고등학생 눈높이

수직선은 실수 체계(R)의 기하학적 모델입니다. 실수의 완비성, 조밀성, 순서 성질이 모두 수직선 위에서 직관적으로 이해됩니다. 이를 확장하면 좌표평면(R^2), 3차원 공간(R^3), 나아가 n차원 유클리드 공간(R^n)으로 일반화할 수 있습니다.

## 🔍 수식을 단계별로 풀어볼까요?

$$\leftarrow \cdots -2, -1, 0, 1, 2 \cdots \rightarrow$$를 함께 읽어봐요!

1. **0을 찾아요.** 수직선의 기준점이에요. 모든 것은 여기서 시작해요.
2. **오른쪽으로 가봐요.** 0에서 오른쪽으로 한 칸 가면 1, 두 칸 가면 2예요. 숫자가 커져요!
3. **왼쪽으로 가봐요.** 0에서 왼쪽으로 한 칸 가면 -1이에요. 음수의 세계랍니다.
4. **이동으로 연산해봐요.** 3에서 오른쪽으로 2칸 가면? 3 + 2 = 5! 덧셈이에요.

수직선 위를 걸어다니면서 덧셈과 뺄셈을 할 수 있어요!

```math-anim
  position: { default: 3, min: -10, max: 10, step: 1, label: { kr: "위치", en: "Position" } }

```

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 슬라이더를 움직이면 수직선 위의 점이 좌우로 이동하며, 화살표로 이동 방향을 볼 수 있어요.
- **관찰 결과:** 양수 방향(오른쪽)으로 갈수록 수가 커지고, 음수 방향(왼쪽)으로 갈수록 작아진다는 것을 직접 확인할 수 있어요!
- **연결 질문:** "수직선 위에서 5에서 시작해 왼쪽으로 8칸 가면 어디에 도착할까?" -- 이렇게 **음수**의 개념을 자연스럽게 이해할 수 있어요!

## 🔗 개념 연결 고리

수직선은 수의 세계를 눈으로 볼 수 있게 해주는 도구예요:

- **덧셈**: 수직선에서 오른쪽으로 이동하는 것이 덧셈이에요.
- **뺄셈**: 수직선에서 왼쪽으로 이동하는 것이 뺄셈이에요.
- **좌표**: 수직선 두 개를 십자로 놓으면 좌표평면이 만들어져요!

## 실생활 활용

- **온도계** -- 온도계가 바로 세로로 세운 수직선이에요! 0도 위는 양수, 아래는 음수.
- **엘리베이터 층수** -- 1층, 2층, 3층... 그리고 지하 1층, 2층은 음수와 같아요.
- **타임라인** -- 역사 연표에서 시간 순서대로 사건을 배치하는 것도 수직선 원리예요.
- **줄자** -- 줄자의 눈금이 바로 수직선이에요! 0부터 시작해서 숫자가 커져요.
- **게임 점수판** -- 보드게임에서 앞으로 3칸, 뒤로 2칸 이동하는 것도 수직선 위의 움직임이에요.
