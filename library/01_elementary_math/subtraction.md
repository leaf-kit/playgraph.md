# 뺄셈 / Subtraction

큰 수에서 작은 수를 빼는 연산입니다.

Taking one number away from another.

$$a - b = c$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

이번에는 뺄셈을 배워볼 거야! 쿠키가 10개 있었는데, 동생한테 4개를 나눠줬어. 남은 쿠키는 몇 개일까? 맞아, 6개! 이렇게 **"빼기"**, **"남기기"**가 뺄셈이야.

풍선 7개를 들고 있었는데 2개가 날아갔어! 남은 풍선은 5개야. 뺄셈은 가지고 있는 것에서 없어지는 것을 세는 거란다.

### 📐 중학생 눈높이

뺄셈은 덧셈의 역연산이에요. a - b = c는 곧 c + b = a와 같은 뜻이죠. 생활비를 관리할 때 가진 돈에서 쓴 돈을 빼서 잔액을 확인하거나, 목표까지 남은 거리를 계산할 때 사용해요.

음수의 개념도 뺄셈에서 출발해요. 3 - 5 = -2처럼, 빼는 수가 더 크면 결과가 음수가 된답니다.

### 🎓 고등학생 눈높이

뺄셈은 덧셈의 역원(additive inverse)을 더하는 것으로 정의됩니다. 즉, a - b = a + (-b)이죠. 이 관점은 대수적 구조에서 매우 중요하며, 벡터 공간에서의 차(difference), 미적분에서의 변화량(delta) 등 고등 수학 전반에 걸쳐 핵심 개념으로 활용됩니다.

## 🔍 수식을 단계별로 풀어볼까요?

$$a - b = c$$를 함께 풀어볼게요!

1. **처음 가진 수(a)를 확인해요.** 예를 들어 a = 10, 블록 10개가 있어요.
2. **빼야 할 수(b)를 확인해요.** b = 4라면, 4개를 빼야 해요.
3. **빼는 과정을 진행해요.** 10개에서 4개를 하나씩 치워볼게요.
4. **남은 수(c)를 세어봐요.** 10 - 4 = 6! 남은 블록이 답이에요.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 블록이 먼저 전부 나타난 뒤, 빼는 수만큼 블록이 사라지는 모습을 관찰할 수 있어요.
- **관찰 결과:** 빼는 수(B)가 커질수록 남는 블록이 적어지고, A와 B가 같으면 블록이 하나도 안 남는다는 걸 발견할 수 있어요!
- **연결 질문:** "뺄셈의 결과를 다시 원래 수로 되돌리려면 어떤 연산이 필요할까?" -- 바로 **덧셈**이에요!

## 🔗 개념 연결 고리

뺄셈은 덧셈과 함께 가장 기초적인 연산 쌍이에요:

- **덧셈**: 뺄셈의 반대예요. 뺀 것을 다시 더하면 원래 수로 돌아와요.
- **수직선**: 수직선 위에서 왼쪽으로 이동하는 것이 뺄셈이에요.
- **나눗셈**: 같은 수를 반복해서 빼는 것이 나눗셈의 원리와 연결돼요.

## 실생활 활용

- **거스름돈 계산** -- 5000원을 내고 3200원짜리 물건을 사면 거스름돈은 1800원이에요.
- **남은 시간 계산** -- 방학이 30일인데 벌써 12일이 지났으면 남은 날은 18일!
- **온도 차이** -- 낮 기온 25도에서 밤 기온 15도를 빼면 일교차 10도를 알 수 있어요.
- **키 차이 비교** -- 형이 165cm이고 나는 145cm이면, 키 차이는 20cm예요.
- **점수 비교** -- 1반 평균 88점에서 2반 평균 82점을 빼면 6점 차이라는 걸 알 수 있어요.
