# 대칭 / Symmetry

어떤 선을 중심으로 양쪽이 똑같은 모양인 것을 대칭이라 합니다.

When both sides of a shape are mirror images of each other.

```math-anim
type: symmetry
params:
  shape: { default: 4, min: 3, max: 8, step: 1, label: { kr: "도형", en: "Shape" } }
  showAxis: { default: true, label: { kr: "대칭축 보기", en: "Show Axis" } }
  animate: { default: true, label: { kr: "애니메이션", en: "Animate" } }
```

- **사람 얼굴**
