# 덧셈 / Addition

두 수를 합하는 가장 기본적인 연산입니다.

The most fundamental operation of combining two numbers.

$$a + b = c$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

안녕, 친구들! 덧셈은 아주 쉽고 재미있는 거야. 상상해봐 -- 왼손에 사탕이 5개 있고, 오른손에 사탕이 3개 있어. 두 손을 모아서 전부 세면? 맞아, 8개! 이게 바로 덧셈이야.

놀이터에서 친구 3명이랑 놀고 있는데, 친구 2명이 더 왔어. 지금 같이 노는 친구는 모두 몇 명일까? 이렇게 **"합치기"**, **"모으기"**가 바로 덧셈이란다!

### 📐 중학생 눈높이

덧셈은 수학에서 가장 기본이 되는 연산이에요. 여러분이 편의점에서 물건을 고를 때 총 가격을 계산하거나, 시험 점수를 합산할 때 자연스럽게 사용하고 있죠.

덧셈에는 **교환법칙**(a + b = b + a)과 **결합법칙**((a + b) + c = a + (b + c))이 있어요. 이 성질들을 이해하면 복잡한 계산도 순서를 바꿔서 더 쉽게 할 수 있답니다.

### 🎓 고등학생 눈높이

덧셈은 자연수에서 시작하여 정수, 유리수, 실수, 복소수까지 확장되는 이항연산(binary operation)입니다. 추상대수학에서는 군(group)의 연산으로 일반화되며, 항등원(0)과 역원(-a)의 개념과 밀접하게 연결됩니다.

벡터의 덧셈, 행렬의 덧셈 등 고등 수학 전반에 걸쳐 덧셈의 구조가 반복적으로 나타나니, 기본 성질을 확실히 이해해두면 큰 도움이 됩니다.

## 🔍 수식을 단계별로 풀어볼까요?

$$a + b = c$$를 함께 살펴봐요!

1. **첫 번째 수(a)를 확인해요.** 예를 들어, a = 5라고 해볼게요. 사탕 5개를 준비하는 거예요.
2. **두 번째 수(b)를 확인해요.** b = 3이라면, 사탕 3개를 더 가져와요.
3. **두 수를 모아요.** 5개와 3개를 한데 모아 전부 세면 되어요.
4. **결과(c)를 구해요.** 5 + 3 = 8! 합쳐진 총 개수가 바로 답이에요.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 슬라이더를 움직이면 블록이 양쪽에 나타나고, 두 그룹의 블록이 합쳐지는 모습을 볼 수 있어요.
- **관찰 결과:** 숫자 A와 숫자 B를 바꿔도 합계가 같다는 것(교환법칙)을 직접 눈으로 확인할 수 있어요!
- **연결 질문:** "합쳐진 블록에서 한쪽 블록을 다시 빼면 어떻게 될까?" -- 이것이 바로 **뺄셈**으로 연결된답니다!

## 🔗 개념 연결 고리

덧셈은 수학의 출발점이에요! 이 개념을 잘 알면 다음과 같은 개념으로 자연스럽게 나아갈 수 있어요:

- **뺄셈**: 덧셈의 반대 연산이에요. "합친 것에서 다시 빼기"를 배우게 돼요.
- **곱셈**: 같은 수를 여러 번 더하는 것을 간단하게 쓴 것이 곱셈이에요. 덧셈을 잘하면 곱셈도 쉬워져요!
- **수직선**: 수직선 위에서 오른쪽으로 이동하는 것이 덧셈을 시각적으로 보여줘요.

## 실생활 활용

- **장보기에서 가격 합산** -- 마트에서 과자 1500원, 우유 2000원을 사면 총 얼마인지 덧셈으로 구해요.
- **점수 합계 계산** -- 국어 85점, 수학 90점, 과학 80점... 총점을 구할 때 덧셈이 필요하죠!
- **시간 더하기** -- 수업 45분에 쉬는 시간 10분을 더하면 총 55분이에요.
- **용돈 모으기** -- 이번 주 3000원, 다음 주 5000원을 모으면 총 8000원! 저금통이 점점 두둑해져요.
- **요리할 때 재료 합치기** -- 밀가루 2컵과 설탕 1컵을 합치면 총 3컵의 재료가 필요해요.
