# 곱셈 / Multiplication

같은 수를 여러 번 더하는 것을 간단하게 표현한 연산입니다.

A shortcut for repeated addition.

$$a \times b = c$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

곱셈은 "같은 수를 여러 번 더하기"를 짧게 쓰는 방법이야! 사탕 봉지가 4개 있고, 각 봉지에 사탕이 3개씩 들어있어. 전부 몇 개일까? 3 + 3 + 3 + 3 = 12를 "4 x 3 = 12"라고 쓰는 거야!

케이크 접시가 3개 있고, 각 접시에 딸기가 5개씩 올라가 있다고 상상해봐. 3 x 5 = 15! 총 딸기가 15개나 있어! 맛있겠다~

### 📐 중학생 눈높이

곱셈은 반복 덧셈을 효율적으로 표현한 연산이에요. 구구단을 외우는 것도 이 때문이죠. 한 팩에 6개씩 들어있는 음료를 5팩 사면 총 30개라는 것을 빠르게 계산할 수 있어요.

곱셈에는 **교환법칙**(a x b = b x a), **결합법칙**, 그리고 덧셈에 대한 **분배법칙**(a x (b + c) = a x b + a x c)이 있어요. 특히 분배법칙은 중학교 이후 수학에서 아주 자주 쓰인답니다.

### 🎓 고등학생 눈높이

곱셈은 자연수의 반복 덧셈에서 출발하지만, 실수의 스칼라 곱, 벡터의 내적/외적, 행렬 곱 등으로 확장됩니다. 환(ring)이라는 대수적 구조에서 곱셈은 두 번째 연산으로 정의되며, 분배법칙이 덧셈과 곱셈을 연결하는 핵심 공리입니다.

## 🔍 수식을 단계별로 풀어볼까요?

$$a \times b = c$$를 함께 살펴봐요!

1. **첫 번째 수(a)를 확인해요.** 예: a = 4, 즉 "묶음이 4개"라는 뜻이에요.
2. **두 번째 수(b)를 확인해요.** b = 3이면, 각 묶음에 3개씩 있다는 뜻이에요.
3. **격자(배열)로 상상해봐요.** 가로 4줄, 세로 3줄로 블록을 늘어놓으면 총 12칸이 보여요.
4. **결과(c)를 구해요.** 4 x 3 = 12! 모든 칸을 세면 그게 답이에요.

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 격자가 가로와 세로로 채워지면서 직사각형 모양이 만들어져요. 슬라이더를 바꾸면 격자 크기가 달라져요.
- **관찰 결과:** A와 B를 서로 바꿔도 격자 칸의 총 수는 같아요(교환법칙!). 또한 격자의 모양이 직사각형의 넓이와 연결된다는 것도 알 수 있어요.
- **연결 질문:** "12칸을 4줄로 똑같이 나누면 한 줄에 몇 칸이 될까?" -- 이것이 바로 **나눗셈**이에요!

## 🔗 개념 연결 고리

곱셈은 덧셈에서 출발해서 넓이, 비례 등 다양한 개념으로 이어져요:

- **덧셈**: 곱셈은 같은 수를 반복 덧셈하는 것에서 시작해요.
- **나눗셈**: 곱셈의 역연산이에요. 곱한 것을 다시 나누면 원래 수가 돼요.
- **직사각형 넓이**: 가로 x 세로가 바로 곱셈이에요! 넓이 구하기와 직접 연결돼요.

## 실생활 활용

- **배열 계산** -- 한 줄에 5명씩 4줄로 서면 총 20명이에요.
- **넓이 구하기** -- 타일이 가로 6장, 세로 4장이면 총 24장이 필요해요.
- **총 개수 세기** -- 한 상자에 달걀이 10개씩, 3상자면 30개!
- **가격 계산** -- 1개에 500원인 빵을 6개 사면 3000원이에요.
- **시간 계산** -- 하루에 2시간씩 7일 공부하면 총 14시간이에요.
