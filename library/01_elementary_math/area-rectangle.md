# 직사각형 넓이 / Rectangle Area

직사각형의 넓이는 가로 곱하기 세로로 구합니다.

The area of a rectangle is width times height.

$$S = a \times b$$

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

직사각형 넓이는 "얼마나 넓은지"를 알아보는 거야! 바닥에 네모난 타일을 깔다고 상상해봐. 가로로 5장, 세로로 3장 놓으면 타일이 총 15장 필요하지? 그게 바로 넓이야!

교실 바닥이 직사각형이잖아. "이 바닥에 색종이를 빈틈없이 붙이려면 몇 장이 필요할까?"를 구하는 게 넓이를 구하는 거란다.

### 📐 중학생 눈높이

직사각형의 넓이는 가장 기본적인 넓이 공식이에요. 가로(a)와 세로(b)를 곱하면 되죠. 단위가 중요한데, 변의 길이가 cm이면 넓이는 cm^2(제곱센티미터)이에요.

이 공식은 다른 모든 도형의 넓이 공식의 기초가 돼요. 삼각형, 평행사변형, 사다리꼴 넓이 모두 직사각형에서 유도할 수 있답니다.

### 🎓 고등학생 눈높이

직사각형의 넓이 S = ab는 정적분의 기하학적 해석과 직결됩니다. f(x) = b인 상수함수를 0부터 a까지 적분하면 ab가 되죠. 이것이 리만 적분의 출발점이며, 넓이의 측도론적(measure theory) 정의로 확장됩니다.

## 🔍 수식을 단계별로 풀어볼까요?

$$S = a \times b$$를 함께 풀어봐요!

1. **가로 길이(a)를 재요.** 예: 직사각형의 가로가 5cm예요.
2. **세로 길이(b)를 재요.** 세로가 3cm예요.
3. **가로와 세로를 곱해요.** 5 x 3 = 15
4. **단위를 붙여요.** 넓이는 15cm^2(제곱센티미터)! "가로 x 세로 = 넓이"를 기억하세요!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 가로와 세로 슬라이더를 움직이면 직사각형의 크기가 변하고, 격자 칸의 수도 함께 변해요.
- **관찰 결과:** 가로를 2배로 늘리면 넓이도 2배가 되고, 가로와 세로를 모두 2배로 늘리면 넓이는 4배가 된다는 것을 발견할 수 있어요!
- **연결 질문:** "직사각형의 테두리 길이는 어떻게 구할까?" -- 이것이 **둘레** 개념으로 연결돼요!

## 🔗 개념 연결 고리

직사각형 넓이는 도형의 세계를 여는 첫 번째 열쇠예요:

- **곱셈**: 가로 x 세로가 곱셈이에요! 곱셈을 잘하면 넓이도 쉬워요.
- **둘레**: 같은 직사각형이라도 넓이와 둘레는 서로 다른 값이에요. 비교해보면 재미있어요!
- **삼각형 넓이**: 직사각형을 대각선으로 자르면 삼각형 두 개가 돼요. 그래서 삼각형 넓이는 직사각형의 절반!

## 실생활 활용

- **방 크기 계산** -- 가로 4m, 세로 3m인 방의 넓이는 12m^2이에요. 가구 배치를 계획할 때 꼭 필요하죠!
- **벽지 필요량** -- 벽면의 가로와 세로를 재서 필요한 벽지의 양을 계산해요.
- **농지 면적** -- 논밭의 크기를 알려면 가로와 세로를 재서 곱하면 돼요.
- **스크린 크기** -- TV나 태블릿 화면의 넓이도 가로 x 세로로 구할 수 있어요.
- **쿠키 만들기** -- 쿠키 반죽을 직사각형 모양으로 펴서 넓이를 구하면 몇 개의 쿠키를 만들 수 있는지 알 수 있어요.
