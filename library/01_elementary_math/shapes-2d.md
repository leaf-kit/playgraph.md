# 평면도형 / 2D Shapes

삼각형, 사각형, 원 등 평면 위에 그릴 수 있는 도형입니다.

Flat shapes like triangles, rectangles, and circles.

```math-anim
type: shapes-2d
params:
  sides: { default: 4, min: 3, max: 8, step: 1, label: { kr: "변의 수", en: "Sides" } }
  size: { default: 3, min: 1, max: 6, step: 0.5, label: { kr: "크기", en: "Size" } }
  showName: { default: true, label: { kr: "이름 표시", en: "Show Name" } }
```
