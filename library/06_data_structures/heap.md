# 힙 / Heap

부모 노드가 항상 자식 노드보다 크거나(최대힙) 작은(최소힙) 완전 이진 트리입니다.

A complete binary tree where parent >= children (max-heap) or parent <= children (min-heap).

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

힙은 **반장 선거**를 떠올려 보세요! 최대 힙에서는 가장 인기 있는(값이 큰) 친구가 항상 맨 꼭대기에 있어요. 새 친구가 들어오면 자기보다 위에 있는 친구와 비교해서, 더 인기가 많으면 위로 올라가요. 항상 가장 인기 있는 친구가 누군지 바로 알 수 있죠!

### 📐 중학생 눈높이

응급실을 생각해 보세요. 먼저 온 사람이 먼저 치료받는 게 아니라, **가장 위급한 환자**가 먼저 치료받죠? 이것이 바로 우선순위 큐이고, 힙으로 구현해요. 힙은 "부모가 항상 자식보다 크거나(또는 작거나) 같다"는 단순한 규칙으로, 최대값이나 최소값을 O(1)에 바로 알 수 있게 해줘요.

### 🎓 고등학생 눈높이

힙은 완전 이진 트리 기반으로 배열을 사용해 구현할 수 있어요(인덱스 i의 부모: (i-1)/2, 자식: 2i+1, 2i+2). 삽입 시 맨 끝에 추가 후 sift-up, 삭제 시 루트를 제거하고 마지막 원소를 올린 뒤 sift-down을 수행합니다. 힙 정렬(O(n log n)), 다익스트라 알고리즘, 허프만 코딩 등에 사용돼요. build-heap은 O(n)에 가능하다는 점도 중요한 성질입니다.

## 🔍 어떻게 작동하는지 알아볼까요?

**최대 힙의 연산을 단계별로 살펴봐요!**

1. **규칙**: 부모 노드는 항상 자식 노드보다 크거나 같아야 해요 (최대 힙)
2. **삽입(Insert)**: 맨 끝에 추가 → 부모와 비교하며 올라가기(sift-up)
   - [50, 30, 40]에 60 삽입 → 맨 끝에 추가 → 30과 비교 → 60이 더 크니 교환 → 50과 비교 → 교환 → [60, 50, 40, 30]
3. **최대값 확인**: 루트(맨 위)를 보면 끝! → O(1)
4. **삭제(Delete Max)**: 루트 제거 → 마지막 원소를 루트로 → 아래로 내려가기(sift-down)
   - [60, 50, 40, 30]에서 60 삭제 → 30을 루트로 → 50과 비교 → 교환 → [50, 30, 40]
5. **배열 표현**: 트리를 배열로 저장! `[60, 50, 40, 30]` — 포인터 없이 인덱스 계산으로 부모/자식 접근

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 최대 힙과 최소 힙을 전환해 보세요. 최대 힙에서는 큰 값이, 최소 힙에서는 작은 값이 항상 루트에 있는 것을 볼 수 있어요.
- **관찰 결과:** 힙은 "전체가 정렬"된 것은 아니에요. 부모-자식 관계만 보장되고, 형제끼리는 순서가 없어요. 이 느슨한 규칙 덕분에 삽입/삭제가 O(log n)으로 빠를 수 있답니다.
- **연결 질문:** 힙으로 배열을 정렬할 수 있을까요? 최대 힙에서 루트를 계속 꺼내면 어떻게 될까요? (힌트: 힙 정렬!)

## 실생활 활용

- **우선순위 큐** — 가장 급한 작업을 먼저 처리해야 할 때 사용해요
- **운영체제 작업 스케줄링** — CPU가 가장 우선순위 높은 프로세스를 먼저 실행해요
- **다익스트라 알고리즘** — 최단 경로를 찾을 때 가장 가까운 노드를 힙에서 꺼내요
- **실시간 데이터 스트림** — "지금까지 들어온 데이터 중 가장 큰 값"을 항상 알 수 있어요
- **메디안 찾기** — 최대 힙과 최소 힙을 함께 쓰면 중앙값을 O(1)에 구할 수 있어요

## 🔗 개념 연결 고리

- **이진 트리(Binary Tree)**: 힙은 완전 이진 트리예요. 이진 트리의 특별한 형태죠
- **퀵 정렬(Quick Sort)**: 힙으로도 정렬할 수 있어요 — 힙 정렬은 항상 O(n log n)이 보장돼요
- **다익스트라(Dijkstra)**: 다익스트라 알고리즘의 핵심 자료구조가 바로 힙이에요

## 핵심 정리

> 삽입/삭제 O(log n), 최대/최소 접근 O(1)
