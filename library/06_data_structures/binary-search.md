# 이진 탐색 / Binary Search

정렬된 배열에서 반씩 줄여가며 원하는 값을 찾는 알고리즘입니다.

Efficiently find a value in a sorted array by halving the search space.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

이진 탐색은 **숫자 맞히기 게임**이에요! 선생님이 1부터 100 사이의 숫자를 생각하면, 여러분은 "50이에요?"라고 물어봐요. "더 커요!"라고 하면 51~100만 생각하면 되죠. 다시 "75예요?" → "더 작아요!" → 51~74만 남아요. 이렇게 매번 반씩 줄이면 7번이면 어떤 숫자든 찾을 수 있어요!

### 📐 중학생 눈높이

두꺼운 영어 사전에서 "Python"을 찾는다고 해 보세요. 첫 페이지부터 한 장씩 넘기나요? 아니죠! 사전을 반쯤 펼치고, P가 앞인지 뒤인지 보고, 다시 반... 이렇게 하면 1000페이지 사전에서도 10번이면 찾아요! 이진 탐색의 조건은 하나 — **데이터가 정렬되어 있어야 한다**는 거예요. 정렬 안 된 데이터에서는 쓸 수 없어요.

### 🎓 고등학생 눈높이

이진 탐색은 정렬된 배열에서 O(log n) 탐색을 보장합니다. 매 반복마다 탐색 범위를 절반으로 줄이므로 log₂n번의 비교로 충분해요. 구현 시 `mid = low + (high - low) / 2`로 오버플로를 방지하는 것이 관례입니다. lower bound, upper bound 변형은 중복 값 처리에 유용하고, 이분 탐색은 배열뿐 아니라 "단조 함수의 경계값 찾기(parametric search)"에도 활용돼요.

## 🔍 어떻게 작동하는지 알아볼까요?

**정렬된 배열 [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]에서 23을 찾아봐요!**

1. **초기 범위**: low=0, high=9, 전체 배열
2. **1단계**: mid=4, arr[4]=16. 23 > 16 → 오른쪽 절반으로! low=5
3. **2단계**: mid=7, arr[7]=56. 23 < 56 → 왼쪽 절반으로! high=6
4. **3단계**: mid=5, arr[5]=23. 23 == 23 → 찾았다!
5. **결과**: 10개 데이터에서 단 3번 비교만으로 찾았어요!
6. **만약 없는 값이면?**: low > high가 되는 순간 "없음"을 반환해요

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 탐색 과정을 보면, 매 단계마다 회색(제외된 부분)이 절반씩 늘어나고 파란색(탐색 범위)이 절반씩 줄어드는 것을 볼 수 있어요.
- **관찰 결과:** 배열 크기가 2배로 커져도 비교 횟수는 1번만 늘어나요! 이것이 O(log n)의 강력함이에요. 10억 개의 데이터에서도 약 30번이면 찾을 수 있답니다.
- **연결 질문:** 이진 탐색을 배열이 아닌 트리 형태로 구현하면 어떤 자료구조가 될까요? (힌트: 이진 탐색 트리!)

## 실생활 활용

- **사전에서 단어 찾기** — 우리가 무의식적으로 하는 사전 검색이 바로 이진 탐색이에요
- **도서관 책 분류 검색** — 도서 번호가 정렬되어 있으니 반씩 좁혀가며 찾아요
- **게임 랭킹 검색** — 정렬된 점수 목록에서 내 순위를 빠르게 찾을 수 있어요
- **Git bisect** — 버그가 생긴 커밋을 이진 탐색으로 찾아요. 1000개 커밋 중 10번이면 발견!
- **가격 비교** — 정렬된 상품 목록에서 원하는 가격대를 빠르게 찾아요

## 🔗 개념 연결 고리

- **배열(Array)**: 이진 탐색의 전제 조건은 정렬된 배열이에요
- **이진 탐색 트리(BST)**: 이진 탐색의 원리를 트리 형태로 구현한 자료구조예요
- **빅오 표기법(Big-O)**: O(log n)이 왜 빠른지, O(n)과 비교하며 이해해 보세요

## 핵심 정리

> 시간 복잡도: O(log n)
