# 해시 테이블 / Hash Table

키(key)를 해시 함수로 변환하여 값(value)을 빠르게 찾는 자료구조입니다.

A data structure that maps keys to values using a hash function.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

해시 테이블은 **도서관 사물함**을 떠올려 보세요! 이름표를 넣으면 마법의 기계가 "너는 7번 사물함이야!"라고 알려줘요. 다음에 찾을 때도 이름표를 넣으면 바로 7번! 이 마법의 기계가 바로 **해시 함수**예요. 이름만 알면 바로 찾을 수 있으니 정말 빠르죠?

### 📐 중학생 눈높이

학교에서 반 번호로 교실을 찾는 것과 비슷해요. "3학년 2반"이라는 키(key)를 들으면 바로 어디로 가야 하는지 알죠? 해시 함수가 키를 받아서 저장 위치를 알려주는 거예요. 그런데 두 학생이 같은 사물함을 배정받는 **충돌(collision)**이 생길 수 있어요! 이때 체이닝(같은 칸에 줄줄이 연결)이나 오픈 어드레싱(빈 칸 찾기) 방법으로 해결한답니다.

### 🎓 고등학생 눈높이

해시 테이블은 평균 O(1)의 탐색/삽입/삭제를 제공하는 강력한 자료구조입니다. 핵심은 **해시 함수의 품질**과 **충돌 해결 전략**이에요. 좋은 해시 함수는 데이터를 균일하게 분산시킵니다. Load factor(적재율)가 높아지면 충돌이 증가하여 최악의 경우 O(n)이 될 수 있으므로, 리사이징(rehashing)이 필요해요. Python의 dict, Java의 HashMap, Rust의 HashMap이 모두 해시 테이블 기반입니다.

## 🔍 어떻게 작동하는지 알아볼까요?

**해시 테이블의 동작을 단계별로 살펴봐요!**

1. **해시 함수 적용**: 키를 넣으면 인덱스가 나와요
   - hash("apple") → 3, hash("banana") → 7
2. **저장(Put)**: 해시 함수가 알려준 인덱스에 값을 저장!
   - 인덱스 3에 "apple: 1000원" 저장
3. **검색(Get)**: 같은 키로 해시 함수를 돌리면 같은 인덱스!
   - hash("apple") → 3 → "1000원" 즉시 찾기
4. **충돌 발생**: hash("cherry") → 3 — 이미 apple이 있네요!
   - 체이닝: 3번 인덱스에 연결 리스트로 연결 `apple → cherry`
   - 오픈 어드레싱: 다음 빈 칸(4번)에 저장
5. **삭제(Delete)**: 키로 위치를 찾고, 해당 데이터를 제거해요

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 키를 입력하면 해시 함수가 인덱스를 계산하고, 해당 위치에 값이 저장되는 것을 볼 수 있어요. 충돌이 발생하면 같은 칸에 여러 값이 연결되는 것도 보여요.
- **관찰 결과:** 테이블 크기가 작을수록 충돌이 자주 발생해요. 좋은 해시 함수는 데이터를 골고루 분산시켜 충돌을 줄여줍니다.
- **연결 질문:** 해시 함수가 모든 키를 같은 인덱스로 보내버리면 어떻게 될까요? 그때의 시간 복잡도는 얼마일까요?

## 실생활 활용

- **전화번호부** — 이름(키)으로 전화번호(값)를 바로 찾을 수 있어요
- **웹 캐시** — URL(키)로 저장된 웹 페이지(값)를 빠르게 불러와요
- **데이터베이스 인덱싱** — 수백만 건의 데이터에서 원하는 레코드를 순식간에 찾아요
- **중복 검사** — 이미 가입된 이메일인지 O(1)으로 확인할 수 있어요
- **프로그래밍 언어의 딕셔너리** — Python의 dict, JavaScript의 Object가 해시 테이블이에요

## 🔗 개념 연결 고리

- **배열(Array)**: 해시 테이블의 내부는 배열로 구현돼요. 해시 함수가 배열 인덱스를 결정하죠
- **연결 리스트(Linked List)**: 체이닝 방식의 충돌 해결에 연결 리스트가 사용돼요
- **트라이(Trie)**: 문자열 키에 특화된 또 다른 검색 자료구조예요

## 핵심 정리

> 평균 접근 O(1), 최악 O(n)
