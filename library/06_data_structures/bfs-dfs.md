# BFS와 DFS / BFS & DFS

그래프를 탐색하는 두 가지 대표적인 방법입니다.

Two fundamental approaches for traversing a graph.

BFS (너비 우선 탐색): 가까운 노드부터 레벨별로 탐색
DFS (깊이 우선 탐색): 한 방향으로 끝까지 탐색 후 되돌아옴

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

BFS는 **돌멩이를 연못에 던진 것**과 같아요! 물결이 동그라미를 그리며 점점 넓게 퍼지죠? 가까운 곳부터 차례로 탐색해요. DFS는 **미로에서 한쪽 벽을 따라 쭉 가는 것**이에요! 막다른 길이면 되돌아와서 다른 길로 가요. 어떤 방법이 더 좋을까요? 상황에 따라 달라요!

### 📐 중학생 눈높이

SNS에서 "나와 가장 가까운 친구"를 찾으려면 BFS가 좋아요. 내 친구(1촌) → 친구의 친구(2촌) 순서로 가까운 사람부터 탐색하니까요. 반면 "이 길이 출구로 이어지는지"를 확인하려면 DFS가 좋아요 — 한 길을 끝까지 가보고, 아니면 돌아와서 다른 길을 가는 거죠. BFS는 **큐**를 쓰고, DFS는 **스택(또는 재귀)**을 써요.

### 🎓 고등학생 눈높이

BFS는 큐 기반으로 레벨 순서 탐색을 수행하며, 무가중 그래프에서 **최단 경로를 보장**합니다. DFS는 스택/재귀 기반으로 한 경로를 끝까지 탐색하며, 위상 정렬, 연결 요소 찾기, 사이클 탐지 등에 활용돼요. 둘 다 시간 복잡도는 O(V+E)이지만, 공간 복잡도에서 차이가 있어요 — BFS는 O(V), DFS는 O(h)(h: 트리 높이)입니다. 문제의 특성에 따라 적절한 탐색 전략을 선택하는 것이 중요해요.

## 🔍 어떻게 작동하는지 알아볼까요?

**같은 그래프를 BFS와 DFS로 탐색해 비교해 봐요!**

그래프: A-B, A-C, B-D, B-E, C-F

**BFS (너비 우선) — 큐 사용:**
1. 시작: A를 큐에 넣기 → 큐: [A]
2. A 방문 → 이웃 B, C를 큐에 → 큐: [B, C]
3. B 방문 → 이웃 D, E를 큐에 → 큐: [C, D, E]
4. C 방문 → 이웃 F를 큐에 → 큐: [D, E, F]
5. D, E, F 차례로 방문 → 결과: **A → B → C → D → E → F**

**DFS (깊이 우선) — 스택 사용:**
1. 시작: A를 스택에 → 스택: [A]
2. A 방문 → 이웃 B로 깊이 들어가기 → 스택: [A, B]
3. B 방문 → 이웃 D로 → 스택: [A, B, D]
4. D 방문 → 더 갈 곳 없음, 되돌아가기 → E 방문
5. 결과: **A → B → D → E → C → F**

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 BFS 모드와 DFS 모드를 번갈아 전환해 보세요. 같은 그래프인데 방문 순서가 완전히 다른 것을 볼 수 있어요!
- **관찰 결과:** BFS는 시작점에서 가까운 순서대로 방문하고, DFS는 한 방향으로 끝까지 간 뒤 돌아와요. 그래서 BFS는 "최단 거리" 문제에, DFS는 "경로 존재 여부"나 "모든 경우 탐색" 문제에 적합해요.
- **연결 질문:** 미로의 최단 경로를 찾으려면 BFS와 DFS 중 어떤 것을 써야 할까요? 왜 그럴까요?

## 실생활 활용

- **미로 탐색** — BFS로 최단 탈출 경로를, DFS로 출구 존재 여부를 확인해요
- **소셜 네트워크 친구 추천 (BFS)** — "나와 2촌인 사람"을 BFS로 찾아서 친구 추천을 해요
- **퍼즐 풀이 (DFS)** — 스도쿠, N-Queen 등의 문제를 백트래킹(DFS)으로 풀어요
- **웹 크롤링 (BFS)** — 구글 봇이 웹 페이지를 BFS로 탐색하며 인덱싱해요
- **파일 검색** — 컴퓨터에서 파일을 찾을 때 DFS(깊은 폴더까지) 또는 BFS(현재 폴더부터)를 사용해요

## 🔗 개념 연결 고리

- **큐(Queue)**: BFS의 핵심 자료구조. 방문할 노드를 순서대로 관리해요
- **스택(Stack)**: DFS의 핵심 자료구조. 되돌아갈 경로를 기억해요
- **그래프 탐색(Graph Traversal)**: BFS와 DFS는 그래프 탐색의 두 가지 기본 전략이에요

## 핵심 정리

> BFS: 큐 사용, 최단 경로 보장. DFS: 스택/재귀 사용, 메모리 효율적.
