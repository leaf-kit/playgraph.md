# 병합 정렬 / Merge Sort

배열을 반으로 나누고, 정렬한 후 합치는 분할 정복 알고리즘입니다.

Divide the array, sort halves, and merge them back.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

병합 정렬은 **카드 나누기 놀이**예요! 카드 뭉치를 반으로 나누고, 또 반으로, 또 반으로... 카드가 1장씩 될 때까지 나눠요. 그다음 두 장씩 비교하면서 순서대로 합쳐요. 작은 것부터 정렬하면서 합치니까, 마지막에는 전부 정렬이 돼 있어요! 조각을 나누고 다시 합치는 거예요.

### 📐 중학생 눈높이

반 친구 32명의 시험 성적을 정렬한다고 해 보세요. 혼자 다 하면 힘들지만, 16명씩 두 그룹으로 나누고, 각 그룹도 또 나누고... 결국 2명씩 비교하면 쉽죠? 정렬된 그룹들을 다시 합치면 끝! 이것이 **분할 정복(Divide and Conquer)** 전략이에요. 항상 O(n log n)이 보장되어서 안정적이에요.

### 🎓 고등학생 눈높이

병합 정렬은 분할 정복 패러다임의 대표적인 알고리즘입니다. 항상 O(n log n) 시간 복잡도를 보장하며, 안정 정렬(stable sort)이에요. 다만 합병 과정에서 O(n)의 추가 메모리가 필요합니다. 외부 정렬(external sort)에 적합하여, 메모리에 다 올릴 수 없는 대용량 데이터를 디스크에서 정렬할 때 사용돼요. Python의 TimSort는 병합 정렬과 삽입 정렬의 하이브리드입니다.

## 🔍 어떻게 작동하는지 알아볼까요?

**배열 [38, 27, 43, 3, 9, 82, 10]을 병합 정렬해 봐요!**

**분할 단계 (반으로 계속 나누기):**
1. [38, 27, 43, 3, 9, 82, 10]
2. [38, 27, 43] | [3, 9, 82, 10]
3. [38] [27, 43] | [3, 9] [82, 10]
4. [38] [27] [43] | [3] [9] [82] [10]

**합병 단계 (순서대로 합치기):**
5. [27, 38] [43] | [3, 9] [10, 82]
6. [27, 38, 43] | [3, 9, 10, 82]
7. [3, 9, 10, 27, 38, 43, 82] 정렬 완료!

**합치는 방법**: 두 정렬된 배열의 앞쪽끼리 비교해서 작은 것을 먼저 넣어요

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 분할 과정을 보면, 배열이 반복적으로 쪼개지다가 합병 과정에서 정렬되며 다시 합쳐지는 것을 볼 수 있어요.
- **관찰 결과:** 분할은 log n번, 각 단계에서 n개의 원소를 합병하므로 총 O(n log n)이에요. 입력이 어떤 순서든 항상 같은 시간이 걸린다는 점이 버블/퀵 정렬과 다른 강점이에요.
- **연결 질문:** 병합 정렬은 추가 메모리가 O(n) 필요해요. 추가 메모리 없이 O(n log n) 정렬을 할 수 있는 방법이 있을까요? (힌트: 힙 정렬!)

## 실생활 활용

- **외부 정렬** — 하드디스크에 있는 테라바이트급 데이터를 정렬할 때 병합 정렬이 핵심이에요
- **안정 정렬이 필요한 경우** — 같은 점수의 학생들이 이름 순서를 유지하도록 정렬해야 할 때
- **데이터베이스 정렬** — DB의 ORDER BY 연산이 내부적으로 병합 정렬을 활용해요
- **Git의 merge** — 두 브랜치를 합칠 때 변경 사항을 병합하는 원리가 비슷해요
- **멀티스레드 정렬** — 분할된 부분을 여러 CPU에서 동시에 정렬하고 합칠 수 있어요

## 🔗 개념 연결 고리

- **퀵 정렬(Quick Sort)**: 둘 다 분할 정복이지만, 병합 정렬은 "합칠 때" 정렬하고 퀵 정렬은 "나눌 때" 정렬해요
- **재귀(Recursion)**: 병합 정렬은 재귀의 대표적인 활용 사례예요
- **빅오 표기법(Big-O)**: 항상 O(n log n)이 보장된다는 점에서 성능 분석의 좋은 예시예요

## 핵심 정리

> 항상 O(n log n), 공간 O(n)
