# 버블 정렬 / Bubble Sort

인접한 두 원소를 비교하여 교환하며 정렬하는 알고리즘입니다.

Sort by repeatedly swapping adjacent elements that are out of order.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

버블 정렬은 **키 순서대로 줄 서기**와 같아요! 옆에 있는 친구와 비교해서 키가 더 큰 친구가 앞에 있으면 자리를 바꿔요. 이걸 앞에서부터 끝까지 반복하면, 제일 큰 친구가 맨 뒤로 가요. 마치 거품(bubble)이 물 위로 뽀글뽀글 올라가는 것 같죠? 그래서 버블 정렬이에요!

### 📐 중학생 눈높이

카드를 정렬한다고 생각해 보세요. 옆에 있는 카드 두 장을 비교해서 순서가 잘못되면 교환! 이걸 계속 반복하면 결국 정렬이 돼요. 단점은? 느려요! 카드가 10장이면 최대 45번(10×9÷2) 비교해야 해요. 100장이면 4950번! 이것이 O(n²)의 의미예요. 하지만 **이해하기 가장 쉬운 정렬**이라서 정렬을 처음 배울 때 꼭 배워요.

### 🎓 고등학생 눈높이

버블 정렬은 인접 원소 비교 기반의 단순한 정렬 알고리즘으로, 시간 복잡도 O(n²)입니다. 이미 정렬된 경우 한 번의 패스만으로 O(n)에 끝낼 수 있는 최적화(early termination)가 가능해요. 안정 정렬(stable sort)이며, 추가 메모리가 필요 없는 제자리 정렬(in-place sort)입니다. 실전에서는 거의 사용되지 않지만, 교환 기반 정렬의 기초를 이해하는 데 중요해요.

## 🔍 어떻게 작동하는지 알아볼까요?

**배열 [5, 3, 8, 1, 2]를 버블 정렬로 정렬해 봐요!**

**1회전 (가장 큰 8이 맨 뒤로):**
1. [**5, 3**, 8, 1, 2] → 5>3이니 교환! → [3, 5, 8, 1, 2]
2. [3, **5, 8**, 1, 2] → 5<8이니 그대로 → [3, 5, 8, 1, 2]
3. [3, 5, **8, 1**, 2] → 8>1이니 교환! → [3, 5, 1, 8, 2]
4. [3, 5, 1, **8, 2**] → 8>2이니 교환! → [3, 5, 1, 2, **8**]

**2회전 (5가 자기 자리로):**
- [3, 5, 1, 2, 8] → [3, 1, 2, **5**, 8]

**3회전, 4회전** 반복 → 최종: [1, 2, 3, 5, 8] 정렬 완료!

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 매 회전(pass)마다 가장 큰 값이 "거품처럼" 오른쪽 끝으로 이동하는 것을 볼 수 있어요. 이미 정렬된 오른쪽 부분은 더 이상 비교하지 않아요.
- **관찰 결과:** 배열 크기가 커질수록 비교 횟수가 급격히 늘어나요. n개의 원소에 대해 약 n²/2번의 비교가 필요하기 때문에, 큰 데이터에서는 매우 비효율적이에요.
- **연결 질문:** 만약 이미 거의 정렬된 배열이라면 버블 정렬이 빨라질 수 있을까요? 어떤 최적화를 할 수 있을까요?

## 실생활 활용

- **간단한 정렬이 필요한 소규모 데이터** — 데이터가 10개 이하면 복잡한 알고리즘보다 간단한 버블 정렬로도 충분해요
- **교육용 정렬 시각화** — 정렬 알고리즘을 처음 배울 때 가장 직관적이에요
- **거의 정렬된 데이터 확인** — 한 번 훑어서 교환이 없으면 이미 정렬된 거예요 (O(n))
- **임베디드 시스템** — 메모리가 극히 제한된 환경에서 추가 공간 없이 정렬할 수 있어요

## 🔗 개념 연결 고리

- **퀵 정렬(Quick Sort)**: 버블 정렬의 O(n²) vs 퀵 정렬의 O(n log n) — 성능 차이를 비교해 보세요
- **병합 정렬(Merge Sort)**: 항상 O(n log n)을 보장하는 더 효율적인 정렬 알고리즘이에요
- **빅오 표기법(Big-O)**: O(n²)이 왜 비효율적인지 빅오로 이해할 수 있어요

## 핵심 정리

> 시간 복잡도: O(n²)
