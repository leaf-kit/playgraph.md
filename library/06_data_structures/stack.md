# 스택 / Stack

후입선출(LIFO) 원칙을 따르는 자료구조입니다.

A Last-In-First-Out (LIFO) data structure.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

스택은 **접시 쌓기**와 같아요! 구내식당에서 접시를 쌓으면, 맨 위에 올린 접시를 먼저 꺼내죠? 중간이나 아래 접시를 빼려면 위에 있는 것부터 하나씩 치워야 해요. "마지막에 넣은 것을 처음에 꺼낸다"는 규칙, 이것이 바로 스택이에요!

### 📐 중학생 눈높이

스마트폰에서 앱을 여러 개 열면, "뒤로가기" 버튼을 누르면 가장 최근에 연 앱으로 돌아가죠? 이게 바로 스택이에요! 프로그래밍에서 "실행 취소(Ctrl+Z)"도 마찬가지예요. 가장 마지막 작업부터 취소되잖아요. 스택은 단순하지만, 컴퓨터 과학에서 **재귀 함수 호출, 수식 계산, 문법 검사** 등 수많은 곳에 쓰이는 정말 중요한 자료구조예요.

### 🎓 고등학생 눈높이

스택은 LIFO(Last-In-First-Out) 원칙을 따르며, push와 pop 두 핵심 연산이 모두 O(1)입니다. 컴파일러에서 괄호 매칭, 후위 표기법(postfix) 수식 계산, 그리고 함수 호출 스택(call stack)이 대표적인 활용이에요. DFS(깊이 우선 탐색)도 스택 기반입니다. 스택 오버플로(stack overflow)는 재귀 호출이 너무 깊어질 때 발생하는데, 이를 방지하기 위해 꼬리 재귀 최적화(tail call optimization)를 사용하기도 해요.

## 🔍 어떻게 작동하는지 알아볼까요?

**스택의 연산을 하나씩 따라가 봐요!**

1. **빈 스택 생성**: `[ ]` (비어 있는 상태)
2. **Push(넣기)**: 맨 위에 추가!
   - Push 10 → `[10]`
   - Push 20 → `[10, 20]`
   - Push 30 → `[10, 20, 30]` ← 30이 맨 위(top)
3. **Peek(확인)**: 맨 위 값을 꺼내지 않고 확인 → 30
4. **Pop(빼기)**: 맨 위부터 꺼내요!
   - Pop → 30 반환, 스택: `[10, 20]`
   - Pop → 20 반환, 스택: `[10]`
5. **isEmpty(비었나?)**: 스택이 비어있는지 확인 → false (10이 남아있어요)

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 Push를 하면 항상 맨 위에 새 요소가 쌓이고, Pop을 하면 맨 위 요소만 사라지는 것을 볼 수 있어요.
- **관찰 결과:** 스택은 한쪽 끝(top)에서만 삽입과 삭제가 일어나기 때문에 항상 O(1)의 성능을 보장해요. 매우 단순하면서도 강력한 자료구조랍니다.
- **연결 질문:** 스택 두 개를 이용해서 큐를 만들 수 있을까요? 어떻게 하면 될지 생각해 보세요!

## 실생활 활용

- **실행 취소(Undo)** — 문서 편집기에서 Ctrl+Z를 누르면 마지막 작업부터 취소돼요
- **괄호 짝 맞추기** — `{[()]}` 같은 코드에서 여는 괄호를 스택에 넣고, 닫는 괄호가 나오면 꺼내서 비교해요
- **함수 호출 스택** — 함수 A가 함수 B를 부르고, B가 C를 부르면, C→B→A 순서로 돌아와요
- **웹 브라우저 뒤로가기** — 방문한 페이지를 스택에 쌓고, 뒤로가기 버튼을 누르면 하나씩 꺼내요
- **미로 탈출** — 막다른 길에 도달하면 직전 갈림길로 되돌아가는(백트래킹) 것도 스택이에요

## 🔗 개념 연결 고리

- **재귀(Recursion)**: 함수의 재귀 호출은 내부적으로 스택을 사용해요
- **연결 리스트(Linked List)**: 연결 리스트의 앞쪽만 사용하면 스택이 돼요
- **큐(Queue)**: 스택과 반대로 먼저 넣은 것을 먼저 빼는 FIFO 자료구조예요

## 핵심 정리

> Push/Pop O(1)
