# 빅오 표기법 / Big-O Notation

알고리즘의 시간 복잡도를 나타내는 표기법입니다.

A notation describing the upper bound of an algorithm's time complexity.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

빅오 표기법은 **"얼마나 오래 걸릴까?"를 표현하는 방법**이에요! 장난감 상자에서 공을 찾는다고 해볼까요? 상자가 1개면 바로 찾지만, 상자가 100개면? 하나씩 열어보면 최대 100번 걸려요. 이때 "상자 수만큼 걸린다"를 O(n)이라고 써요. 만약 어떤 마법으로 항상 1번만에 찾으면? O(1)이라고 해요!

### 📐 중학생 눈높이

게임 로딩 시간을 생각해 보세요. 맵이 2배로 커지면 로딩이 얼마나 길어질까요? O(n)이면 2배, O(n²)이면 4배, O(log n)이면 거의 안 늘어나요! 빅오는 **데이터가 커질 때 속도가 어떻게 변하는지**를 알려주는 도구예요. 알고리즘을 비교할 때 "이 알고리즘은 O(n log n)이고, 저것은 O(n²)이니까 데이터가 크면 이게 낫다"라고 판단할 수 있어요.

### 🎓 고등학생 눈높이

빅오 표기법은 알고리즘의 점근적 상한(asymptotic upper bound)을 나타냅니다. 상수와 낮은 차수 항은 무시해요 — `3n² + 5n + 2`는 O(n²)입니다. 빅오(O)는 최악, 빅오메가(Ω)는 최선, 빅세타(Θ)는 평균을 나타내요. 실제 성능은 상수 계수, 캐시 효율성, 입력 패턴에 따라 달라질 수 있으므로, 빅오만으로 모든 것을 판단할 수는 없다는 점도 중요해요.

## 🔍 어떻게 작동하는지 알아볼까요?

**각 복잡도가 실제로 어떤 의미인지 예시로 알아봐요!**

1. **O(1) — 상수 시간**: 배열에서 인덱스로 접근. 데이터가 아무리 많아도 1번!
2. **O(log n) — 로그 시간**: 이진 탐색. 1000개 데이터에서 약 10번이면 찾아요
3. **O(n) — 선형 시간**: 배열을 처음부터 끝까지 훑기. 데이터 2배 → 시간 2배
4. **O(n log n) — 선형 로그 시간**: 병합 정렬, 퀵 정렬. 효율적인 정렬의 한계
5. **O(n²) — 이차 시간**: 버블 정렬. 데이터 2배 → 시간 4배! 큰 데이터에서는 너무 느려요
6. **비교**: n=1000일 때 → O(1)=1, O(log n)≈10, O(n)=1000, O(n log n)≈10000, O(n²)=1000000

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 입력 크기를 늘려 보세요. O(1) 그래프는 수평선이고, O(n²) 그래프는 급격히 치솟는 것을 볼 수 있어요. O(log n)은 거의 평평하게 느껴질 정도로 천천히 증가하죠.
- **관찰 결과:** n이 작을 때는 O(n)이든 O(n²)이든 차이가 거의 없어요. 하지만 n이 커지면 그 차이는 엄청나게 벌어져요. 그래서 "데이터가 커질 때"를 기준으로 알고리즘을 평가하는 거예요.
- **연결 질문:** 왜 모든 알고리즘을 O(1)로 만들 수 없을까요? 시간과 공간 사이에는 어떤 관계가 있을까요?

## 실생활 활용

- **알고리즘 성능 비교** — "이 검색은 O(log n)이고 저 검색은 O(n)이니까 데이터가 크면 이것을 쓰자!"
- **시스템 설계 시 선택 기준** — 서버에 100만 명이 접속할 때, O(n²) 알고리즘은 감당이 안 돼요
- **면접 준비** — IT 기업 면접에서 "시간 복잡도가 뭐예요?"는 단골 질문이에요
- **예산 계획** — 서버 비용을 예측할 때, 사용자가 늘면 처리 시간이 얼마나 증가하는지 알아야 해요
- **게임 최적화** — 프레임 드롭 없이 수천 개의 오브젝트를 처리하려면 복잡도가 중요해요

## 🔗 개념 연결 고리

- **이진 탐색(Binary Search)**: O(log n)의 대표적인 예시예요
- **버블 정렬(Bubble Sort)**: O(n²)의 대표적인 예시. 퀵/병합 정렬의 O(n log n)과 비교해 보세요
- **해시 테이블(Hash Table)**: O(1) 접근의 대표적인 자료구조예요

## 핵심 정리

> O(1) < O(log n) < O(n) < O(n log n) < O(n²)
