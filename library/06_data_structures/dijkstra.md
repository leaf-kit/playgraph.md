# 다익스트라 알고리즘 / Dijkstra's Algorithm

가중 그래프에서 한 정점으로부터 다른 모든 정점까지의 최단 경로를 구하는 알고리즘입니다.

An algorithm for finding the shortest path from a source vertex to all other vertices in a weighted graph.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

다익스트라 알고리즘은 **가장 빠른 등굣길 찾기**예요! 집에서 학교까지 여러 길이 있는데, 각 길마다 걸리는 시간이 달라요. "지금까지 가장 가까운 장소"부터 하나씩 확인하면서, 더 빠른 길을 발견하면 갈아타요. 이렇게 하면 모든 장소까지의 가장 빠른 길을 찾을 수 있답니다!

### 📐 중학생 눈높이

카카오맵에서 "최단 경로"를 누르면 나오는 길이 바로 다익스트라의 결과예요! 핵심은 **"현재까지 알려진 가장 가까운 장소부터 처리"**하는 것이에요. 마치 물이 가장 낮은 곳부터 채워지는 것처럼요. 이때 "가장 가까운 것"을 빨리 꺼내기 위해 **힙(우선순위 큐)**을 사용해요. 단, 음수 가중치(마이너스 거리)가 있으면 제대로 작동하지 않아요!

### 🎓 고등학생 눈높이

다익스트라 알고리즘은 그리디 알고리즘의 일종으로, 매 단계에서 최소 거리 정점을 선택합니다. 우선순위 큐(이진 힙) 사용 시 O((V+E) log V), 피보나치 힙 사용 시 O(V log V + E)입니다. 음의 가중치가 있으면 벨만-포드(Bellman-Ford) 알고리즘을, 모든 쌍 최단 경로가 필요하면 플로이드-워셜(Floyd-Warshall)을 사용해요. 네트워크 라우팅(OSPF 프로토콜), 게임 AI, 로봇 경로 계획 등에 핵심적으로 활용됩니다.

## 🔍 어떻게 작동하는지 알아볼까요?

**간단한 그래프에서 다익스트라를 따라가 봐요!**

A→B(4), A→C(2), B→D(3), C→B(1), C→D(5), 시작: A

1. **초기화**: A=0, B=∞, C=∞, D=∞ (시작점만 0, 나머지 무한대)
2. **A 처리** (가장 가까운 미방문 노드):
   - B까지: 0+4=4 (∞보다 작으니 갱신!) → B=4
   - C까지: 0+2=2 (∞보다 작으니 갱신!) → C=2
3. **C 처리** (거리 2로 가장 가까움):
   - B까지: 2+1=3 (4보다 작으니 갱신!) → B=3
   - D까지: 2+5=7 → D=7
4. **B 처리** (거리 3):
   - D까지: 3+3=6 (7보다 작으니 갱신!) → D=6
5. **결과**: A→A=0, A→C=2, A→B=3(A→C→B), A→D=6(A→C→B→D)

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 각 노드의 거리 값이 탐색이 진행되면서 점점 줄어드는(갱신되는) 것을 볼 수 있어요. 한 번 확정된 노드의 거리는 더 이상 바뀌지 않아요.
- **관찰 결과:** 다익스트라의 핵심은 "탐욕적(greedy) 선택"이에요. 매번 가장 가까운 미방문 노드를 선택하면, 그 노드까지의 최단 거리가 확정됩니다. 이 성질이 알고리즘의 정확성을 보장해요.
- **연결 질문:** 만약 간선의 가중치가 음수라면 왜 다익스트라가 실패할까요? 이미 확정된 거리가 나중에 바뀔 수 있다면?

## 실생활 활용

- **지도 내비게이션 (최단 경로)** — 카카오맵, 구글맵의 길 찾기가 다익스트라(또는 변형)를 사용해요
- **네트워크 라우팅 프로토콜** — 인터넷 패킷이 가장 빠른 경로를 찾아 전달돼요 (OSPF 프로토콜)
- **게임 AI 경로 탐색** — NPC가 장애물을 피해 목적지로 가는 경로를 계산해요
- **물류 최적화** — 택배 배송 경로를 최적화하여 시간과 비용을 절약해요
- **소셜 네트워크** — 두 사람 사이의 "관계 거리"를 계산할 수 있어요

## 🔗 개념 연결 고리

- **그래프 탐색(Graph Traversal)**: 다익스트라는 BFS의 가중치 버전이라고 볼 수 있어요
- **힙(Heap)**: 다익스트라에서 "가장 가까운 노드"를 빠르게 꺼내기 위해 힙을 사용해요
- **BFS와 DFS**: 가중치가 없는 그래프에서는 BFS만으로 최단 경로를 구할 수 있어요

## 핵심 정리

> 우선순위 큐(힙) 사용 시 O((V+E) log V). 음수 가중치에는 사용 불가.
