# 그래프 탐색 / Graph Traversal

그래프의 모든 정점을 체계적으로 방문하는 방법입니다.

Systematically visiting all vertices in a graph.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

그래프 탐색은 **동네 탐험**과 같아요! 집(정점)들이 있고, 길(간선)로 연결되어 있어요. 모든 집을 빠짐없이 방문하고 싶은데, 이미 간 집은 다시 안 가고, 빠뜨리는 집도 없어야 해요. 어떻게 하면 모든 집을 체계적으로 돌아볼 수 있을까요?

### 📐 중학생 눈높이

카카오맵이나 네이버 지도에서 길 찾기를 할 때, 앱은 도로 네트워크(그래프)를 탐색해서 경로를 알려줘요. 인스타그램에서 "팔로우 추천"도 사람들 간의 관계 그래프를 탐색한 결과예요. 그래프 탐색은 **연결 관계가 있는 모든 문제**를 푸는 기본 도구예요. 네트워크, 지도, SNS, 추천 시스템 모두 그래프 탐색이 기반이에요.

### 🎓 고등학생 눈높이

그래프 탐색은 정점(V)과 간선(E)으로 구성된 그래프의 모든 정점을 방문하는 알고리즘입니다. BFS/DFS가 기본이며, 방문 배열(visited)로 중복 방문을 방지해요. 인접 리스트 표현 시 O(V+E), 인접 행렬 표현 시 O(V²)입니다. 연결 요소(connected component) 찾기, 사이클 탐지, 위상 정렬, 강한 연결 요소(SCC) 분해 등 고급 그래프 알고리즘의 기반이 됩니다.

## 🔍 어떻게 작동하는지 알아볼까요?

**그래프 탐색의 핵심 개념을 알아봐요!**

1. **그래프 표현**: 정점(노드)과 간선(연결)으로 구성
   - 인접 리스트: 각 정점이 자신과 연결된 정점 목록을 가짐 (메모리 효율적)
   - 인접 행렬: V×V 크기의 2차원 배열 (빠른 연결 확인)
2. **방문 표시**: visited 배열로 이미 방문한 정점을 기록해요
3. **탐색 시작**: 시작 정점을 선택하고 방문 표시
4. **이웃 탐색**: 현재 정점의 이웃 중 미방문 정점을 찾아 방문
5. **반복**: 더 이상 방문할 정점이 없을 때까지 계속!
6. **비연결 그래프**: 모든 정점에서 시작해봐야 연결 요소를 모두 찾을 수 있어요

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 간선 수를 늘려보세요. 정점 수가 같아도 간선이 많아지면 그래프가 훨씬 복잡해지는 것을 볼 수 있어요. 방문 순서도 달라지죠!
- **관찰 결과:** 시간 복잡도가 O(V+E)인 이유는, 모든 정점을 한 번씩(V), 모든 간선을 한 번씩(E) 확인하기 때문이에요. 간선이 많을수록 탐색 시간도 늘어나요.
- **연결 질문:** 만약 그래프의 간선에 "거리"나 "비용" 같은 가중치가 있다면, 최단 경로를 어떻게 찾을 수 있을까요?

## 실생활 활용

- **소셜 네트워크 분석** — 페이스북에서 "함께 아는 친구"를 찾는 것이 그래프 탐색이에요
- **지도 내비게이션** — 도로 네트워크를 그래프로 표현하고 최적 경로를 탐색해요
- **웹 크롤링** — 검색 엔진이 웹 페이지의 링크를 따라가며 인터넷을 탐색해요
- **전력망 분석** — 정전 시 영향받는 지역을 그래프 탐색으로 파악해요
- **추천 시스템** — 넷플릭스가 비슷한 취향의 사용자를 그래프에서 찾아 영화를 추천해요

## 🔗 개념 연결 고리

- **BFS와 DFS**: 그래프 탐색의 두 가지 핵심 전략. 문제에 따라 적절히 선택하세요
- **다익스트라(Dijkstra)**: 가중 그래프에서의 최단 경로 탐색으로 확장돼요
- **큐(Queue)와 스택(Stack)**: 그래프 탐색에서 다음 방문 노드를 관리하는 자료구조예요

## 핵심 정리

> BFS: O(V+E), DFS: O(V+E)
