# 이진 트리 / Binary Tree

각 노드가 최대 두 개의 자식 노드를 가지는 트리 자료구조입니다.

A tree where each node has at most two children.

## 🌟 선생님의 다정한 설명

### 🎈 초등학생 눈높이

이진 트리는 **가족 족보**와 비슷해요! 맨 위에 할아버지(루트)가 있고, 할아버지에게는 자녀가 최대 두 명이에요. 그 자녀들도 각각 최대 두 명의 자녀가 있죠. 이렇게 위에서 아래로 가지가 쭉 뻗어나가는 나무 모양이에요. 진짜 나무를 뒤집어 놓은 것 같죠?

### 📐 중학생 눈높이

스무고개 게임을 떠올려 보세요! "동물이야? → 네 → 날 수 있어? → 아니 → 물에 살아? → 네 → 물고기!"처럼, 매번 두 가지 중 하나를 선택하며 답에 가까워지죠. 이진 트리도 각 노드에서 왼쪽 또는 오른쪽으로 가면서 원하는 데이터를 찾아가요. 이런 **이분법적 구조** 덕분에 검색이 빨라질 수 있답니다.

### 🎓 고등학생 눈높이

이진 트리는 재귀적 자료구조로, 각 노드가 왼쪽/오른쪽 서브트리를 가집니다. 순회 방식으로 전위(preorder), 중위(inorder), 후위(postorder), 레벨(level-order) 순회가 있어요. 완전 이진 트리(complete binary tree)는 배열로 효율적으로 표현할 수 있고(인덱스 i의 자식: 2i+1, 2i+2), 이것이 힙의 기반이 됩니다. 수식 트리(expression tree), 허프만 코딩(Huffman coding) 등 다양한 응용이 있어요.

## 🔍 어떻게 작동하는지 알아볼까요?

**이진 트리의 구조와 순회를 알아봐요!**

1. **노드 구조**: 각 노드는 `[왼쪽 자식 | 데이터 | 오른쪽 자식]`으로 구성돼요
2. **루트(Root)**: 맨 위의 시작 노드예요 — 트리의 입구!
3. **리프(Leaf)**: 자식이 없는 맨 아래 노드예요 — 나뭇잎 같죠?
4. **순회 방법들**:
   - 전위(Preorder): 나 → 왼쪽 → 오른쪽 (부모 먼저!)
   - 중위(Inorder): 왼쪽 → 나 → 오른쪽 (정렬 순서!)
   - 후위(Postorder): 왼쪽 → 오른쪽 → 나 (자식 먼저!)
5. **깊이와 높이**: 루트에서 노드까지의 거리가 깊이, 노드에서 가장 먼 리프까지가 높이예요

### 🌟 선생님의 관찰 노트

- **관찰 내용:** 시각화에서 깊이를 늘리면 노드 수가 급격히 증가하는 것을 볼 수 있어요. 깊이 2면 7개, 깊이 3이면 15개, 깊이 4면 31개!
- **관찰 결과:** 깊이가 1 증가할 때마다 노드 수가 약 2배로 늘어나요. 이것이 이진 트리가 데이터를 효율적으로 저장할 수 있는 이유예요 — 적은 깊이로 많은 데이터를 담을 수 있거든요.
- **연결 질문:** 이진 트리에 "왼쪽은 작은 값, 오른쪽은 큰 값"이라는 규칙을 추가하면 어떤 자료구조가 될까요?

## 실생활 활용

- **파일 시스템** — 폴더 안에 폴더가 있는 구조가 바로 트리예요
- **조직도** — 사장님 아래에 부장님, 부장님 아래에 과장님... 트리 구조죠!
- **의사 결정 트리** — AI가 판단할 때 "예/아니오"를 따라가며 결론을 내리는 구조예요
- **수식 계산기** — `(3 + 5) * 2`를 트리로 표현하면 연산 순서가 자연스럽게 결정돼요
- **HTML DOM** — 웹 페이지의 구조도 트리예요. `<html>` 안에 `<head>`와 `<body>`가 있죠

## 🔗 개념 연결 고리

- **이진 탐색 트리(BST)**: 이진 트리에 정렬 규칙을 추가한 자료구조예요
- **힙(Heap)**: 완전 이진 트리에 최대/최소 규칙을 추가한 자료구조예요
- **재귀(Recursion)**: 트리 순회는 재귀의 가장 아름다운 활용 사례예요

## 핵심 정리

> 높이 h일 때 최대 노드 수: 2^(h+1) - 1
